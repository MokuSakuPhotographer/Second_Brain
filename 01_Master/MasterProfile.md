# カメラ機材

「10_撮影機材」内のノートから自動表示する。同フォルダ内の機材は、手放し済み・売却済みを除いて所有済みとして管理する。自動一覧では、手放し済み・売却済み・購入検討・購入対象外・廃棄済みを除外する。機材の追加や分類・所有状況の変更は、Dataviewの再集計後に表示へ反映される。

## カメラボディ

```dataview
LIST
FROM "10_撮影機材"
WHERE type = "camera_body"
AND !contains(["手放し済", "手放し済み", "売却済", "売却済み", "購入検討", "購入対象外", "廃棄済", "廃棄済み"], default(所有状況, ""))
SORT file.name ASC
```
