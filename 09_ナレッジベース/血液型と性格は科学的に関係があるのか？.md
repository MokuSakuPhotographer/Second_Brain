# 血液型と性格は科学的に関係があるのか？

## 1. 結論

**「A型は几帳面」「B型はマイペース」といった血液型による性格分類には、現時点で十分な科学的根拠がない。**

血液型と性格の関係を検証した研究や論文は実際に存在する。しかし、大規模な統計研究では、血液型によって性格に実質的な違いが生じるという証拠は得られていない。

一方、一部の研究では特定の性格特性との弱い関連が報告されているため、あらゆる関連が完全に否定されたわけでもない。

重要なのは、**統計的な関連が見つかることと、血液型が性格を決定することは別問題**という点である。

## 2. 大規模研究による検証

### 2014年：日本とアメリカの1万人以上を対象とした研究

心理学者の縄田健悟氏は、2014年に『心理学研究』で「血液型と性格の無関連性」という論文を発表した。

日本とアメリカの合計1万人以上の調査データを用い、血液型と性格との関係を統計的に検証した研究である。

**主な結果**

| 検証内容 | 結果 |
|---|---|
| 調査対象 | 日本・アメリカの1万人以上 |
| 検証した性格関連項目 | 68項目 |
| 統計的な有意差がなかった項目 | 65項目 |
| 血液型による説明率 | 0.3%未満 |

68項目中65項目で統計的な有意差が認められず、血液型による性格項目のばらつきの説明率も極めて小さかった。

**この研究から、血液型は個人の性格を予測するうえで実用的な情報ではないと判断できる。**

### 2015年：関連が検出された研究

2015年には、弘前大学などの研究者によって、日本人1,427人を対象とした研究が『PLOS ONE』に発表された。

この研究では、性格特性の一つである「持続性（Persistence）」とABO式血液型との間に統計的に有意な関連が検出された。

ただし、以下の点に注意が必要である。

- 観測された効果は小さく、血液型による説明率は約0.6%であった。
- 研究者自身が予備的な結果として慎重な解釈を求めている。
- 血液型が直接性格を決定する仕組みは証明されていない。

つまり、**弱い統計的関連が検出されたとしても、一般的な血液型性格診断の正しさが証明されたわけではない。**

## 3. 血液型と性格に生物学的な関係はあるのか？

### 血液型を決める仕組み

ABO式血液型は、親から受け継ぐ遺伝子によって決定される。

A型・B型・AB型・O型の違いは、主に赤血球表面などに存在する糖鎖抗原の違いに由来する。

一方、性格は多数の遺伝的要因に加え、成育環境、経験、社会的な影響などが複雑に関与して形成される。

### ABO遺伝子とDBH遺伝子の関係

2015年の研究では、ABO遺伝子の近くに存在する「DBH遺伝子」に注目している。

DBH遺伝子は、神経伝達物質のドーパミンをノルアドレナリンへ変換する酵素に関係している。

そのため、ABO遺伝子とDBH遺伝子の遺伝的な結び付きが、性格特性との統計的関連を生じさせる可能性が仮説として検討された。

しかし、これは確立したメカニズムではない。

**「血液型に関係する遺伝子が、性格に影響する可能性」と「血液型そのものが性格を決めること」は区別する必要がある。**

## 4. 血液型に対する思い込みが性格に影響する可能性

血液型そのものよりも、血液型に対する社会的な固定観念が人間の行動に影響する可能性がある。

### 自己成就的予言とは？

自己成就的予言（Self-fulfilling Prophecy）とは、ある予測や思い込みが人々の行動に影響し、結果としてその予測に沿った現象が生じることを指す。

例えば、次のような流れが考えられる。

> 「B型はマイペース」という固定観念が広まる
>
> ↓
>
> 周囲がB型の人物をそのイメージで評価する
>
> ↓
>
> 本人の自己認識や行動にも影響する
>
> ↓
>
> 結果として、固定観念に沿った行動が生じる可能性がある

この場合、血液型が生物学的に性格を決めたのではなく、**周囲の評価や本人の思い込みが行動を変化させた**ことになる。

### 2025年の日本の研究

経済産業研究所（RIETI）の2025年のディスカッション・ペーパーでは、日本における血液型に対する固定観念と社会的な結果との関連が分析された。

「B型は自己中心的」といった偏見が、結婚や就業などに影響する可能性や、自己成就的予言の可能性が報告されている。

ただし、これはディスカッション・ペーパー段階の研究であり、確立された科学的結論ではない。

## 5. 科学的な評価のまとめ

| 検証対象 | 科学的な評価 |
|---|---|
| 血液型は遺伝によって決まる | 確立した事実 |
| 性格には遺伝的要因が関係する | 科学的根拠あり |
| 血液型と一部の性格特性に関連がある | 弱い関連を報告した研究が存在 |
| A型は几帳面、B型はマイペース | 十分な科学的根拠なし |
| 血液型から個人の性格を予測できる | 支持されていない |
| 血液型への思い込みが行動に影響する | 研究・検討されている |

## 6. 最終的な結論

血液型と性格との関係は科学的に検証されてきたが、一般的な血液型性格診断を裏付ける十分な証拠は得られていない。

一部の研究では弱い統計的関連が報告されているものの、その効果は小さく、直接的な因果関係も確立していない。

また、性格形成には複数の遺伝子や環境要因が関わるため、ABO式血液型という単一の分類によって人間の性格を説明することは困難である。

したがって、**血液型性格診断は、科学的な性格分析ではなく、社会的・文化的に広まった分類として理解するのが妥当である。**

なお、性格が血液型を決定するわけではないことは事実だが、それ自体は血液型と性格に関連がないことの証明にはならない。両者の関連の有無は、統計的な検証によって判断する必要がある。
