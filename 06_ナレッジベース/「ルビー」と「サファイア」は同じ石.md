# 「ルビー」と「サファイア」は同じ石

## ルビーとサファイアは同じ石である

厳密には「同じ鉱物」です。ただし色が違うことで名前が変わっています。

どちらも元は コランダム（和名：鋼玉）という鉱物です。

分類するとこうなります。

- 赤色のコランダム → ルビー
- 青色のコランダム → サファイア

色の違いは混ざっている微量元素によります。

- ルビー：主にクロム（Cr）が混ざる → 赤色
- 青いサファイア：鉄（Fe）やチタン（Ti）が関与 → 青色

さらに面白いことに、「サファイア＝青だけ」ではありません。

実はサファイアには、

- ピンクサファイア
- イエローサファイア
- グリーンサファイア
- ホワイトサファイア
- パープルサファイア

など色違いが存在します。

つまり宝石業界では、

「赤ならルビー、それ以外の色のコランダムは全部サファイア」

という扱いです。

ただし境界が少し曖昧で、赤とピンクの中間色は「ルビー判定かピンクサファイア判定か」で鑑別機関や市場評価が分かれることがあります。

ちなみに硬さはどちらも同じで、モース硬度9です。天然石では ダイヤモンド の次に硬い部類になります。
## なんでサファイアだけ色々な色があるの？

理由は「サファイア」が実は“青い石の名前”ではなく、“ルビー以外のコランダム全部”だからです。

さっきの話を少し言い換えると、

コランダム  
↓  
赤 → ルビー  
赤以外 → サファイア

という分類なんです。

なので、コランダムに混ざる元素が変わるたびに色が変わって、その全部がサファイア側に入ります。

例を挙げると、

- 鉄（Fe） → 黄色系、緑系
- 鉄＋チタン（Fe＋Ti） → 青色
- 微量元素の組み合わせ変化 → 紫、オレンジなど
- 不純物が少ない → 無色（ホワイトサファイア）

になります。

逆にルビーは「クロムによって赤くなったもの」とかなり条件が限定されています。

しかも面白いのが、「赤くなれば全部ルビー」でもないんです。

クロムが少なくて、

赤寄りピンク → ピンクサファイア  
十分赤い → ルビー

になります。

だからルビーは“サファイア一族のエリート赤担当”みたいな立ち位置です。

さらに希少なものとしては、オレンジとピンクが混ざった パパラチアサファイア があり、これは夕焼けや蓮の花の色に例えられて非常に高価になります。

つまり本質的には、

「サファイアに色が多い」のではなく、

「赤以外を全部サファイアに押し込んだ結果、色が多く見える」が正解です。![[サファイアとルビーは同じ石まとめ.png|600]]
