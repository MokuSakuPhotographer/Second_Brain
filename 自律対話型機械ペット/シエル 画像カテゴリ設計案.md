# シエル｜日常自撮り画像カテゴリ・制作計画

## 1. 概要・目的

シエルとの日常会話において、返答内容に対応した自撮り風画像を送信する機能を実装する。

画像はリアルタイム生成せず、**事前に手動生成した画像をカテゴリ別に保存し、会話内容に応じて選択する方式**を採用する。

### 採用理由

- ComfyUIによる自動生成でGPU負荷が増加することを防ぐ。
- LM StudioのモデルをVRAMに常駐させ、会話の応答速度を維持する。
- ゲームや動画編集への影響をなくす。
- キャラクターの容姿・画風・画像品質を統一する。
- 画像生成の待機時間なしで、文章と画像を送信できる。
- 将来的なリアルタイム画像生成への拡張性を維持する。

## 5. 画像制作時の統一ルール

### キャラクター

- [ ] シエルの顔立ちを統一する。
- [ ] 髪型・髪色を統一する。
- [ ] キャラクターの基本的な体格を維持する。
- [ ] 基本衣装を中心とし、就寝時や外出時のみ衣装を変更する。

### 撮影表現

- [ ] スマートフォンによる自撮り風を基本とする。
- [ ] カメラ目線と自然な目線外しを組み合わせる。
- [ ] ポーズやアングルが単調にならないようにする。
- [ ] 一部には第三者が撮影したような自然なスナップ構図も採用する。
- [ ] 画像は縦長比率で統一する。

### 背景・生活空間

- [ ] シエルの自室のデザインを決める。
- [ ] 家具の配置や配色に一貫性を持たせる。
- [ ] 昼夜による照明の変化を表現する。
- [ ] 同じ部屋が別の画像で大きく変化しないようにする。
- [ ] 屋外画像についても画風・色調を統一する。

### 品質管理

- [ ] 顔・手・指の破綻を確認する。
- [ ] 衣装や装飾品の不自然な変形を確認する。
- [ ] キャラクターの同一性を確認する。
- [ ] 画像カテゴリと実際の行動が一致しているか確認する。
- [ ] 保存する画像は手動で品質を確認し、採用する。

## 6. 画像と会話内容の整合性

シエルが画像を送信する場合、**返答文の内容と選択画像の状況を一致させること**を重視する。

### 基本原則

1. 会話の文脈から画像送信の必要性を判定する。
2. 画像送信が必要な場合、使用可能な画像カテゴリを参照する。
3. 会話内容に適したカテゴリを選択する。
4. 選択したカテゴリに矛盾しない返答文を生成する。
5. 該当カテゴリから画像を選び、文章とともに送信する。

### 具体例

**適切な組み合わせ**

- 返答：「ソファでくつろいでたよ」
- 画像：ソファでくつろぐシエル

**不適切な組み合わせ**

- 返答：「料理をしていたよ」
- 画像：PC作業中のシエル

画像カテゴリに存在しない行動を返答する場合は、無理に画像を添付しない。

また、通常の会話すべてを事前生成画像の内容に制限する必要はない。

## 9. 最終方針

初期段階では、**9カテゴリ・38枚の画像セット**を制作する。

ただし、全画像を一度に完成させず、使用頻度の高い日常生活カテゴリ23枚から制作を開始する。

画像の制作・選定は手動で行い、画像の管理・選択ロジック・会話連携に必要なコード変更はCodexに任せる。

### 重要な設計要件

1. **会話速度の維持：** 画像送信によってLLMの応答速度を低下させない。
2. **視覚的な一貫性：** シエルの容姿・衣装・生活空間に統一感を持たせる。
3. **会話との整合性：** シエルの発言と送信画像の内容が矛盾しないようにする。
