# 旅館業法について

# 旅館業法に基づく宿泊拒否の法的要件と実務対応ガイド

## 旅館・ホテルの「公共性」と宿泊拒否の原則

旅館やホテルといった宿泊施設は、単なる商業施設ではなく、**社会的なインフラとしての「公共的役割」を担っています**。この公共性に鑑み、旅館業法は原則として、事業者による宿泊の拒否を禁じている。

しかしながら、法律は同時に、従業員や他の宿泊客の安全と快適な環境を守るための例外規定も設けている。特に、2023年12月13日に施行された改正旅館業法は、近年社会問題化しているカスタマーハラスメント（特定要求行為）への対応を新たに定め、事業者が従業員を守りながら質の高いサービスを維持するための法的根拠を整備した。

本ガイドは、この最新の法的枠組みに基づき、ホテルや旅館が宿泊を拒否できる「正当な理由」と、拒否できない「不当な理由」の境界線を明確にし、実務における具体的な対応策を分かりやすく解説することを目的とする。

-------------------------------------------------------------------------------

## **1. ホテルが宿泊を拒否できる「正当な理由」とは**

宿泊拒否はあくまで例外的な措置だが、旅館業法第5条第1項で定められた「正当な理由」は、事業者が資産、評判、そして全ての顧客と従業員の安全を守るための、積極的なリスク管理ツールである。これらの規定は、施設の安全、公序良俗、そして従業員の健全な労働環境を保護するために不可欠であり、その戦略的重要性を正しく理解することが求められる。

### **1.1. 特定感染症の患者である場合（旅館業法第5条第1項第1号）**

宿泊を拒否できる理由の一つは、宿泊しようとする者が**「特定感染症」の患者である場合**。

ここでいう特定感染症とは、「感染症の予防及び感染症の患者に対する医療に関する法律」に規定される一類感染症、二類感染症、新型インフルエンザ等感染症、または入院の勧告・措置が講じられている指定感染症などを指す。

- **拒否できる具体例**：
    - 宿泊希望者が、診断等により特定感染症に罹患していることが明らかになった場合。
- **対象外のケース**：
    - 五類感染症である新型コロナウイルス感染症（Covid-19）のみを理由とした宿泊拒否はできない。また、たとえ特定感染症の患者であっても、医師の診断によって他者への感染リスクが低いと判断された場合（例：退院基準を満たした結核患者）は、宿泊拒否ができない。

### **1.2. 違法行為や風紀を乱すおそれがある場合（同第2号）**

宿泊者が**賭博その他の違法行為**や、**公の秩序や善良な風俗を乱す行為をするおそれがあると客観的に認められる場合**も、宿泊を拒否できる。この「公の秩序や善良な風俗」とは、主に**宿泊施設内の安全・平穏の維持**を目的とする。

これらの拒否基準は、確定した違法行為に限定されず、客観的に認識可能なリスクも含まれるため、ホテル側が混乱を未然に防ぐための予防的措置を講じることを可能にする。ただし、この「おそれがある」の判断は、ホテルの主観ではなく**客観的な事実や合理的な根拠**に基づいて行われる必要がある。

- **対象者の例**：
    - 暴力団員、暴力団関係者、その他反社会的勢力に属する者。
- **過去の行為**：
    - 過去に当該施設内で暴力、脅迫、騒音といった迷惑行為を行った経歴がある者
- **即時拒否の可能性**：
    - 粗暴な言動や器物損壊など、行為そのものの違法性が高い場合は、たとえ一度きりの行為であっても、直ちに宿泊拒否の正当な理由となり得る。

### **1.3. カスタマーハラスメント（特定要求行為）を繰り返した場合（同第3号）**

2023年の法改正で新設されたこの項目は、従業員への過重な負担を防ぎ、他の宿泊客へのサービス品質を維持することを目的としている。この拒否事由が成立するためには、宿泊者の要求が法律の定める「特定要求行為」に該当し、かつその行為が「繰り返される」という二つの要件を満たす必要がある。
「特定要求行為」に該当しうる行為の具体例は以下の通りである。

- **不当なサービス要求**：
    - 契約にない送迎サービスの提供
    - 宿泊料の不当な割引や、根拠のない部屋のアップグレードの強要
- **従業員の長時間拘束**：
    - 対面や電話で、長時間にわたり理不尽な要求やクレームを続ける行為
- **不相当な手段・態様**：
    - 暴行・傷害（身体的攻撃）
    - 脅迫・侮辱・暴言（精神的攻撃）
    - 土下座の要求など、社会通念上不相当な手段での要求
- **泥酔による迷惑行為**：
    - 泥酔状態にあり、スタッフに対して介抱を繰り返し求めるなど、他の宿泊客へのサービス提供を著しく阻害する行為
- **特定の従業員への固執**：
    - 特定の従業員のみに対応させるよう繰り返し要求する行為

---

### 1.4. 満室やその他の事由がある場合（同第4号）

 客室が物理的に満室である場合のほか、施設のサービス提供能力に余裕がない場合も宿泊を拒否できる。

- **サービス提供能力の限界**：
    - 施設の営業規模縮小などにより、宿泊者に対して十分なサービスが提供できない状況も「余裕がないとき」に含まれる。
- **都道府県の条例**：
    - 各都道府県は、地域の実情に応じて条例で独自の拒否事由を定めることができる。例えば、他の宿泊客への著しい迷惑行為、支払い能力の欠如、宿帳への記載拒否などが規定されている場合がある。詳しくは以下に記述する。

### 1.4-1.埼玉県旅館業法施行細則

- **著しい迷惑行為をするおそれがある場合**
    - 他の宿泊客に対し、著しい迷惑を及ぼすおそれがあると認められる場合。
- **不当な契約を要求する場合**
    - 施設に対して、宿泊に関し不当な要求をするおそれがあると認められる場合。
- **不適当な服装や不潔な行為**
    - 著しく不潔な身体または服装をしているため、他の宿泊客に迷惑を及ぼすおそれがあると認められる場合。
- **支払い能力の欠如**
    - 宿泊料金の支払能力がないと明らかに認められる場合。
- **宿帳の記載拒否**
    - 旅館業法第7条に規定する事項（氏名、住所、電話番号など）の記載を拒んだとき。

### **1.5. 宿泊拒否の際の義務**

宿泊を正当な理由に基づき拒否した場合、ホテル・旅館側には法的な義務が発生する。営業者は、**拒否した日時、理由、経緯等を記録した書面を作成し、その書面を3年間保存**しなければならない。

-------------------------------------------------------------------------------

以上の通り、宿泊を拒否できる理由は法律で厳格に定められている。これらの法的根拠を正しく理解することは、次に解説する「拒否できないケース」との境界線を明確にし、法的リスクを回避する上で不可欠である。

-------------------------------------------------------------------------------

## **2. ホテルが宿泊を拒否できない「不当な理由」とは**

旅館業の公共的役割を鑑み、宿泊拒否の判断は主観や偏見ではなく、客観的な事実に基づいて行わなければならない。特に、障害などを理由とする差別的な取扱いは決して許されないという法の精神を遵守する必要があり、障害者差別解消法の遵守は、全ての宿泊事業者にとっての責務である。

### **2.1. 障害を理由とする差別的な取扱い**

旅館業法第5条には、障害があることは宿泊拒否の理由として一切記載されていない。したがって、**障害のみを理由とした宿泊拒否は明確に違法**である。ホテル・旅館には、障害者差別解消法に基づき、障害のある宿泊者に対して「合理的配慮」を提供する義務がある。

- **宿泊拒否に該当しない「合理的配慮」の具体例**：
    
    以下のような要求は、障害のある方が健常者と同様にサービスを享受するための正当なものであり、これらを理由に宿泊を拒否することはできない。
    
    - フロントでの筆談や、車椅子利用者のベッドへの移乗介助といった、社会的障壁を取り除くための要求
    - 介護者や身体障害者補助犬（盲導犬、介助犬、聴導犬）の同伴
    - その行為が障害の特性によるものであることが把握できる場合（例：悪意なく、場に応じた音量調整が苦手な場合など）
    - 過去に受けた差別的取扱いに対する謝罪の要求
- **過去の重大な差別事例**：
    
    障害を理由とする宿泊拒否は、社会的に厳しく断罪される。
    
    - 2003年には、**ハンセン病元患者の宿泊を拒否したホテル**が、旅館業法違反で営業停止処分を受け、経営者が略式起訴されるという重大な事件が発生した。
    - また、「障害者が所属する団体」という属性のみを理由に、**予約の相談すら一律に拒否した事例**は、障害者差別解消法が禁じる差別的取扱いに該当すると指摘されている。

### **2.2. 営業者側の過失に対する正当な要求**

予約ミスや部屋の清掃不備など、ホテル側の不手際によって宿泊客が損害を被り、その謝罪や補償を求める行為自体は、**正当な権利行使であり宿泊拒否の理由にはならない**。ただし、その要求の手段や態様がエスカレートし、前述のカスタマーハラスメント（特定要求行為）に該当するレベルに至った場合は、この限りではない。

-------------------------------------------------------------------------------

これらの規定は、誰もが安心して宿泊施設を利用できる社会を実現するための重要なルールである。万が一、法に則り正当な理由で宿泊を拒否したにもかかわらず顧客がそれに応じない場合、事態は次の法的フェーズへと移行する。

-------------------------------------------------------------------------------

## **3. 宿泊拒否に応じない宿泊者への法的対処法**

ホテル側が旅館業法に基づき正当な理由で宿泊を拒否した後、客が退去を拒んだり、さらなる迷惑行為に及んだりした場合、その行為は旅館業法の問題から、**刑法や民法が適用される領域へと移行する**。この時点でもはや問題は宿泊の権利ではなく、施設内で**違法行為**が行われているという事態である。したがって、対応も顧客サービスから、**セキュリティおよび法執行**へとシフトさせる必要がある。ここからの対応は、施設の秩序と全利用者の安全を守るための、事業者としての正当な権利行使となる。

### **3.1. 警察への通報・協力要請（刑法上の犯罪）**

客の行為がエスカレートし、犯罪に該当する可能性がある場合、速やかに**警察に協力を依頼すること**が不可欠である。想定される主な犯罪と具体例は以下の通りである。

| 犯罪名 | 具体的な行為の例 |
| --- | --- |
| **暴行罪・傷害罪** | スタッフや他の宿泊客に暴力を振るう、物を投げつける。 |
| **威力業務妨害罪** | 大声で怒鳴り続ける、長時間ロビーに居座るなどして、他の業務を妨害する。 |
| **脅迫罪** | 「SNSに悪評を書き込むぞ」と脅すなど、生命・身体・財産等に害を加える旨を告知する行為。 |
| **強要罪** | 暴行や脅迫を用いて、土下座や金品の支払いを無理やり要求する。 |
| **器物損壊罪** | ホテルの備品や設備を意図的に破壊する。 |

### **3.2. 民事上の損害賠償請求**

刑事罰とは別に、民事上の責任を追及できる可能性もある。理不尽な要求や長時間のクレーム対応によって従業員が精神的苦痛を受けたり、他の客への対応が滞ったりした場合、ホテルが被った損害について、行為者に対して不法行為に基づく損害賠償を請求することが可能。

-------------------------------------------------------------------------------

## **まとめ**

旅館業法はホテル・旅館に対し、二つの重要な役割を課している。一つは、社会インフラとして誰もが公平に利用できる「公共性」の担保。そしてもう一つは、従業員と全ての宿泊客の安全と快適性を守るための秩序維持である。

2023年の法改正は、この二つの要請のバランスを取るための重要な一歩と言える。カスタマーハラスメントに対しては、事業者が毅然と対応するための法的根拠が整備された一方で、障害等を理由とする不当な差別は引き続き厳しく禁じられており、合理的配慮の提供が強く求められている。

日本における旅館・ホテルは、時に「公共交通機関」にもなぞらえられるほど、社会生活に不可欠な基盤である。この公共的役割を深く認識し、法律を正しく理解・運用することこそが、事業を守り、その社会的役割を全うするための根源的な経営責任である。
