# アルプラゾラム

## 薬の基本情報

| 項目 | 内容 |
|---|---|
| 一般名 | アルプラゾラム |
| 分類 | ベンゾジアゼピン系抗不安薬 |
| 主な効能・効果 | 心身症（自律神経失調症など）に伴う身体症状、不安・緊張・抑うつ・睡眠障害など |
| 現在の服薬 | **朝1錠・昼1錠・晩1錠**（本人申告） |
| 1錠の規格 | **未確認（0.4mg／0.8mgなどを薬袋で確認）** |
| 製品名・メーカー | 未確認 |

## 作用

脳内のGABAの働きを増強して不安や緊張を軽減する。自律神経失調症の原因を根治する薬とは限らない。

## 主な副作用

- 比較的みられる：**眠気**、ふらつき、集中力・反応速度の低下、だるさ。
- その他：口渇、悪心、腹部不快感、便秘、下痢、記憶への影響など。
- **重大な注意**：連用による依存、急な減量・中止による離脱症状（強い不安、不眠、振戦、けいれん、せん妄など）。呼吸抑制なども報告。

## 注意事項

- **急にやめない。** 減量・中止は必ず処方医の計画に従う。
- 酒、睡眠薬、鎮静作用をもつ薬と併用すると眠気や判断力低下が増すことがある。
- **トラベルミン配合錠も眠気を生じ得る。** 併用内容は処方医・薬剤師に確認する。
- 添付文書は服薬中の自動車運転・危険な機械操作に注意を求めている。運転の可否を自己判断しない。
- 長期服用の継続必要性は、自己中止ではなく主治医と定期的に再評価する。
