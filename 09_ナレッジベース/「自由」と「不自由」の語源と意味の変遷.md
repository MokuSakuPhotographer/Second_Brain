# 「自由」と「不自由」の語源と意味の変遷

> [!summary] 要点
> 「自由」は明治時代に新しく作られた語ではない。古くは「思うままにできる」という意味を持ち、ときには「身勝手な振る舞い」を非難する言葉でもあった。一方、「不自由」は明治以前から「思うようにならない」という意味で使われていた。**両者は語の基本的な意味で対立するため、二重否定にはならない。**

## 1. 古い「自由」には複数の意味があった

「自由」は中国の古典に用例がある漢語で、日本でも奈良時代の『続日本紀』（777年）に用例が見られる。[1]

中心にあるのは、**自分の思うとおりにできること／他から制約されないこと**である。しかし、行動の内容や社会規範との関係によって評価が異なった。

| 用法 | 意味・評価 | 史料の例 |
|---|---|---|
| 思うままにできる | 中立的・肯定的になり得る | 『続日本紀』（777年）「升降自由」 |
| 身勝手に振る舞う | 否定的 | 『金勝寺文書』（1185年）で、権限によらない押領を「自由」と表現 |
| 仏教的な自由 | 他のものに縛られない・自らをよりどころとする境地 | 『正法眼蔵』『沙石集』などの仏教文献にも用例 |

中世の法令や文書では「自由狼藉」など、勝手な行動を批判する意味が目立つ。だが、**「自由＝悪」という一義的な言葉だったわけではない**。[1]

### 仏教での「自由」

仏教的な説明では、「自らに由る（よる）」という字義を通じて、他に依存せず独立自在である状態を表す。[2] これは、法律で保障された政治的自由とは異なる文脈の用法である。なお、これを「自由」という語の唯一の起源とみなすのは適切ではない。漢籍にも複数の古い用法があるためである。[1]

## 2. 「不自由」は明治以前から存在した

『精選版 日本国語大辞典』は、「不自由」の用例として『蒙求抄』（1529年頃）の「起座が不自由也」を挙げる。[3]

また、井原西鶴『日本永代蔵』（1688年）には、暮らしが苦しく思うようにならないことを表す「不自由」の例がある。[3]

つまり、**「不自由」は近代的な liberty / freedom の訳語が広まる前から、「思うようにならない」「不便である」という意味で使われていた**。

## 3. 否定的な「自由」に「不」を付けても二重否定ではない理由

鍵は、**言葉の意味**と**その行動への評価**を区別することにある。

| 言葉 | 基本的な意味 | 社会的な評価 |
|---|---|---|
| 自由 | 思うようにできる | 行為によって肯定・中立・否定 |
| 自由狼藉 | 勝手に振る舞い、乱暴・不法を働く | 否定的 |
| 不自由 | 思うようにできない | 多くの場合は不便・困難として否定的 |

「自由狼藉」の否定的評価は、**思うように行動することが他人や規則を害した**点に向けられている。

一方、「不自由」の「不」は、**思うようにできるという状態そのもの**を打ち消す。否定している対象が異なるため、「否定的な自由」＋「不」＝肯定、という計算にはならない。

## 4. 西洋語の翻訳によって新しい意味が加わった

19世紀には「自由」が英語 *freedom* や *liberty* の訳語として使用されるようになる。1862年の『英和対訳袖珍辞書』にも見られるため、**明治維新後に初めて訳されたわけではない**。[1]

福沢諭吉は『西洋事情』初編（1866年）で、「自由」を法を恐れないわがままという意味ではないと説明した。[4][5]

さらに『学問のすゝめ』初編（1872年）では、自由とわがままの境界を、他人を妨げるかどうかに見いだした。[6]

この翻訳によって、従来の「思うまま」という意味に加え、**言論・信仰・政治参加など、不当な拘束から守られる自由**という政治・法的な意味が広がった。国立国会図書館によると、1881年頃までには「自由」「権利」が広く普及した。[7]

> [!note] 注意
> *Freedom* と *liberty* は文脈によって使い分けられるが、「前者は精神だけ、後者は政治だけ」と厳密に分割できるわけではない。また、翻訳後も「自由気まま」など古い意味は残り続けている。

## 5. 意味変化のまとめ

| 時代・領域 | 「自由」の主な用法 |
|---|---|
| 古代 | 思うままに行動する・制約されない |
| 中世の法令・訴訟文書 | 勝手な自己主張を非難する用法が目立つ |
| 仏教文献 | 独立自在・束縛されない状態を肯定的に表す |
| 戦国〜江戸期 | 便宜や思いどおりになることを示す肯定的な用法も広がる |
| 幕末〜明治 | 近代的な権利・政治的自由の意味が普及する |

**古い意味が消滅したのではなく、新しい意味が重なって現代に受け継がれた**と捉えるのが正確である。[1]
