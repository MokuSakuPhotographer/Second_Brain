## 導入目的

- 外玄関に設置し、来訪者・不審な動き・夜間の玄関周辺を確認するための防犯カメラ候補。
- 配線しにくい屋外に設置する前提で、バッテリー内蔵とソーラーパネル給電を重視する。
- IP65対応のため、雨が当たる可能性がある場所でも使いやすい候補。
- 2K 3MP解像度とカラーナイトビジョンにより、昼夜の状況確認をしやすくする。

## 購入検討メモ

| 観点 | メモ |
|---|---|
| 良い点 | ソーラー給電前提なので、外玄関で電源配線を引きにくい場合に扱いやすい |
| 良い点 | 視野角が水平111°あり、玄関前の広めの範囲を見渡しやすい |
| 良い点 | IP65で屋外設置向き |
| 良い点 | microSD最大512GB対応で、クラウド契約なしでもローカル保存できる |
| 良い点 | 人物検知・アクティビティゾーン対応で、通知の絞り込みがしやすい |
| 注意点 | 2.4GHz Wi-Fiのみ対応。設置予定位置で電波強度を事前確認する |
| 注意点 | 常時録画向きというより、バッテリー運用のイベント録画用途として考える |
| 注意点 | ソーラーパネルは日照条件に左右されるため、外玄関の向きと日陰時間を確認する |
| 注意点 | microSDカードは別売り。屋外・監視用途では高耐久カードを検討する |
| 注意点 | 防犯そのものを保証する機器ではないため、照明・鍵・センサー類と組み合わせて考える |
