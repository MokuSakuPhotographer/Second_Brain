# ドリアの発祥

作成日時: 2025年10月12日 20:10
タグ: #知識, #面白
まとめ済: Yes

ドリアは日本発祥であり、フランスにもイタリアにも、**サリー・ワイル**(後述)の出身国であるスイスにも存在しない。


# 生まれ

1930年頃、横浜ホテルニューグランドの初代総料理長であった**サリー・ワイル**が、体調を崩した欧州の銀行家のために即興で提供した料理。

その時は、バターライスに芝エビのクリーム煮とベシャメルソースをかけ、オーブンで焼き上げたもの。

<aside>
📰

**ベシャメルソースとは？**

日本で言うホワイトソースのこと。フランス料理や専門的に言う時にはベシャメルソースと呼ばれることがある。

</aside>

この料理が好評であり、「Shrimp Doria」(エビとご飯の混合)としてア・ラ・カルトのレギュラーメニューとなった。

それがさらに広まり、現在は日本の洋食料理の代表になっている。

<aside>
📰

**ア・ラ・カルトとは？**

日本で言う一品料理のこと。コース料理ではなく、単品で料理を選ぶスタイル。

</aside>

# 料理名の由来

イタリア・ジェノヴァの名門貴族、**ドーリア家**の16世紀に活躍した海軍提督の**アンドレア・ドーリア**に由来する和製外来語。

# イタリア人に「ドリア」と言うと？

おそらく、「なにそれ？」と言われる。

一番近い説明は「risotto gratinato（リゾット・グラティナート）である。
