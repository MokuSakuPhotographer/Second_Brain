# ベタヒスチン

## 薬の基本情報

| 項目 | 内容 |
|---|---|
| 一般名 | ベタヒスチンメシル酸塩 |
| 分類 | 鎮暈薬 |
| 主な効能・効果 | メニエール病・メニエール症候群・眩暈症に伴うめまい、めまい感 |
| 現在の服薬 | **朝1錠・晩1錠**（本人申告） |
| 1錠の規格 | **未確認（6mg／12mgなどを薬袋で確認）** |
| 製品名・メーカー | 未確認 |

## 作用

ヒスタミン類似作用をもち、内耳の循環などに関わることでめまい症状の改善を目的に使われる。根本治療と同義ではない。

## 主な副作用

- **悪心・嘔吐**、発疹（添付文書で報告）。
- ヒスタミン類似作用のため、**胃酸分泌が増える可能性**が指摘されている（特に消化性潰瘍の既往・活動性潰瘍に注意）。

## 注意事項

消化性潰瘍、気管支喘息、褐色細胞腫などがある場合は処方医に伝える。胸焼けや胃の不快感が続く場合は、服用歴と症状の記録を持って処方医・薬剤師に相談する。自己判断で中止・増減しない。
