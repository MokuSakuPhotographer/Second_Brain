# シエルペットのQOL向上機能アイデア

## 概要

シエルペットはすでに、以下のような機能を備えている。

- 自然言語による会話
    
- 長期記憶
    
- 感情・人格表現
    
- 音声入出力
    
- Discord連携
    
- Obsidian Vault検索
    
- PC状態の取得
    
- Nature Remoなどを利用した家電操作
    
- カメラ・人物検出
    
- PTZ操作
    
- 室温・湿度などの環境情報取得
    

今後は単純に機能を増やすよりも、これらを連携させて、

> **現在の状況を理解し、必要な処理を適切なタイミングで実行するAI**

へ発展させる方向が、QOL向上につながりやすい。

---

# 1. コンテキスト型ルーチン

最も優先度が高い機能。

現在取得できる複数の情報を組み合わせて、シエル自身が現在の状況を判定し、適切な処理を実行する。

## 使用する情報の例

- 現在時刻
    
- 人物検出
    
- PCの使用状態
    
- 室温・湿度
    
- カレンダー
    
- 家電の状態
    
- 会話履歴
    
- リマインダー
    
- 外出・帰宅状態
    

## 例：室温管理

```
23:30
＋
部屋に人物がいる
＋
PC使用中
＋
室温27℃
↓
「室温が27℃あります。冷房を26℃にしますか？」
```

操作を事前許可している場合は、自動でエアコンを調整することも可能。

## 例：帰宅検知

```
人物を検出
＋
PCがスリープ状態
＋
18:00以降
↓
照明ON
エアコン状態確認
PC Wake-on-LAN
「おかえりなさい」
```

単純な「センサー反応」ではなく、複数条件を組み合わせて判断するのが重要。

---

# 2. 状況対応型リマインダー

一般的なリマインダーは、

> 「18時に通知する」

という時刻基準で動作する。

シエルではこれを、

> **その行動を実行すべき状況になったとき通知する**

仕組みに発展させる。

## 例

会話中に、

> 「明日仕事に行く前にAmazonの返品を持っていかないとな」

と言った場合、

```
タスク
Amazon返品

条件
明日
＋
外出を開始
```

として記録。

外出しようとしたときに、

> 「Amazonの返品を持ちましたか？」

と通知する。

## メリット

通常のリマインダーよりも、

- 通知が早すぎない
    
- 通知が遅すぎない
    
- 行動と直接結びつく
    
- 時刻を指定する必要がない
    

という利点がある。

# 3. マスター状態管理

現在の人物検出を発展させ、単なる「いる・いない」ではなく、現在の生活状態をシエル内部で管理する。

## 状態例

```
HOME
AWAY
SLEEP
WORKING
GAMING
BUSY
IDLE
```

これを他のシステムの共通ステータスとして利用する。

---

## AWAY

外出したと判断した場合。

```
AWAY
↓
エアコン状態確認
PC状態確認
不要機器OFF
防犯監視強化
通知先をDiscordへ変更
```

---

## HOME

帰宅した場合。

```
HOME
↓
監視モード解除
室温確認
エアコン調整
必要ならPC起動
音声会話モード有効化
```

---

## GAMING

ゲーム中の場合。

```
GAMING
↓
不要な自律発話を抑制
重要通知のみ表示
PC負荷の高いAI処理を制限
```

---

## SLEEP

就寝中の場合。

```
SLEEP
↓
音声発話禁止
照明OFF
不要PC処理停止
重要通知のみスマートフォンへ送信
```

# 4. Google Calendar連携【済】

シエルに予定表を認識させる。

単純な予定確認だけでなく、予定を生活ルーチンのトリガーとして利用する。

## 基本機能

例えば、

> 「今日何か予定ある？」

と聞くと、

```
17:00 夜勤
出発推奨 16:10
```

のように回答する。

---

## カレンダー基準ルーチン

```
勤務90分前
↓
予定確認
天気確認
必要な持ち物確認
交通状況確認
↓
必要な情報だけ通知
```

固定時刻で生活していない場合でも、予定そのものを基準にできる。

# 7. 発話タイミング判断

シエルが、

> **何を話すか**

だけでなく、

> **今話しかけてもよいか**

まで判断する。

自律AIでは非常に重要な機能。

## 状況別の動作例

|状況|シエルの動作|
|---|---|
|ゲーム中|発話を最小限にする|
|動画視聴中|重要通知のみ|
|PC作業中|短文通知|
|IDLE|自律会話を許可|
|外出中|Discordへ通知|
|深夜|音声発話停止|
|睡眠中|緊急通知以外停止|

これにより、

> 「便利だが頻繁に話しかけてきて邪魔」

という問題を抑えられる。

# 8. Context Engine

これらを個別機能として実装するだけでなく、中央に**Context Engine**を設置すると拡張しやすい。

## 構造

```
センサー
カメラ
PC状態
時刻
カレンダー
室温・湿度
Nature Remo
会話履歴
Obsidian
リマインダー
        │
        ▼
┌─────────────────┐
│   Context Engine │
└─────────────────┘
        │
        ▼
現在のマスター状態
HOME
AWAY
WORKING
GAMING
SLEEP
BUSY
IDLE
        │
        ▼
┌────────────────┐
│   Action Engine │
└────────────────┘
        │
        ├─ 音声発話
        ├─ Discord
        ├─ PC操作
        ├─ 家電操作
        ├─ リマインダー
        └─ 通知
```

Context Engineは、

> 「現在何が起きているのか」

を判断する。

Action Engineは、

> 「その状況で何をするのか」

を担当する。

この2つを分離すると、機能追加が容易になる。

```

状況に応じて、

```

を自動実行できる仕組みを作る。

# 最終的なシエルの方向性

現在のシエルは、

> **見える・聞ける・話せる・覚えられるAI**

という段階まで発展している。

次の目標は、

> **状況を理解できるAI**

その次が、

> **状況に応じて適切な行動を選択できるAI**

となる。

最終的には、

```
認識
↓
状況理解
↓
判断
↓
行動
↓
結果確認
```

というサイクルを自律的に回せる構造が理想となる。

特に、

1. **マスター状態管理**
    
2. **Context Engine**
    
3. **状況対応型リマインダー**
    
4. **Action Engine**
    

の4つを中心に構築すると、既存のシエルの機能を大きく作り直さずに統合できる。

単純なAIチャットボットではなく、

> **生活環境そのものを認識して動くパーソナルAI**

へ発展させるための中核機能となる。
