## 導入目的

- [[テーブルフォト参考レポート]] で、テーブルフォトをする場合の必須級候補として記載。
- 三脚の中心からカメラ位置を横へ逃がし、料理・物撮りを真上から撮りやすくする。
- α7系 + 標準ズームや単焦点の範囲なら、耐荷重2kg内に収めやすい。

## 購入検討メモ

| 観点 | メモ |
|---|---|
| 良い点 | 三脚を大きく動かさず、カメラ位置だけを前後・上下に調整しやすい |
| 良い点 | 真上構図と斜め俯瞰の両方に使いやすい |
| 良い点 | カウンターウェイト用フックがあり、重心対策を取りやすい |
| 注意点 | 三脚側の剛性が不足すると、アームだけ強くしても不安定になる |
| 注意点 | カメラを横に出すほど転倒リスクが上がるため、ウェイト併用前提 |
| 注意点 | 耐荷重2kgを超える構成では使用しない |

## 関連運用

- テーブルフォト、料理撮影、俯瞰物撮りで使用。
- カメラ・レンズ・雲台の合計重量を確認し、三脚側には重りを追加する。
- より安定させる場合は [[購入検討品/SmallRig RA-S280A Air-Cushioned Light Stand with Arm 3737|より堅牢なライトスタンド候補]] とは別に、三脚自体の剛性も見直す。
