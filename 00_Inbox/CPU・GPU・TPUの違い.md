# CPU・GPU・TPUの違いと仕組み

## 1. 概要

コンピューターには、計算処理を実行するためのさまざまなプロセッサーが存在する。

代表的なものが、**CPU・GPU・TPU**の3種類である。

いずれもデータを処理する半導体であるが、それぞれ設計思想や得意とする計算が異なる。

|項目|CPU|GPU|TPU|
|---|---|---|---|
|正式名称|Central Processing Unit|Graphics Processing Unit|Tensor Processing Unit|
|日本語名称|中央処理装置|画像処理装置|テンソル処理装置|
|主な役割|コンピューター全体の処理|大量の並列計算|AI向けの行列演算|
|得意分野|複雑な処理・制御|並列処理|機械学習・AI|
|汎用性|非常に高い|高い|特定用途に特化|
|代表的な製品|Intel Core、AMD Ryzen|NVIDIA GeForce、AMD Radeon|Google Cloud TPU|

**最大の違いは、どのような計算を効率的に処理するよう設計されているかという点である。**

---

## 2. CPU：Central Processing Unit

### CPUとは

CPUは、コンピューターの基本的な計算や制御を担当する汎用プロセッサーである。

OSの動作、アプリケーションの実行、各種機器の制御など、幅広い処理を担当する。

### 特徴

- 複雑な命令を柔軟に実行できる。
    
- 条件分岐や逐次処理が得意である。
    
- 複数のコアを使用した並列処理も可能である。
    
- コンピューター全体の動作を制御する。
    

### 処理のイメージ

```
CPU

仕事A → 処理 → 完了
仕事B → 処理 → 完了
仕事C → 処理 → 完了
仕事D → 処理 → 完了
```

※単一の処理系列を示した概念図。実際のマルチコアCPUは複数の処理を並行して実行できる。

CPUは、少数から数十程度の高機能なコアを使用して、複雑な処理を効率的に実行する設計が一般的である。

### 具体例

Intel Core i9-14900KFはCPUに分類される。

ゲームの進行管理、物理演算の一部、AIの制御、アプリケーションの実行などを担当する。

---

## 3. GPU：Graphics Processing Unit

### GPUとは

GPUは、もともと画像や映像を高速に処理するために開発されたプロセッサーである。

現在では、画像処理だけでなく、AIや科学技術計算にも広く利用されている。

### 特徴

- 大量の計算を同時並行で実行することが得意である。
    
- 多数の演算器を搭載している。
    
- 画像処理、3D描画、AIの学習・推論などに利用される。
    
- CPUより汎用性は限定されるが、特定の並列計算では高い処理性能を発揮する。
    

### 処理のイメージ

```
GPU

仕事A → 処理 → 完了
仕事B → 処理 → 完了
仕事C → 処理 → 完了
仕事D → 処理 → 完了
仕事E → 処理 → 完了
仕事F → 処理 → 完了
       ↑
   大量の並列処理
```

GPUは、大量のデータに対して類似した演算を繰り返す処理に適している。

例えば、ゲーム画面を構成する大量のピクセルや頂点の計算を並列化できる。

### 具体例

NVIDIA GeForce RTX 4090はGPUを搭載したグラフィックカードである。

主な用途は以下のとおり。

- 3Dゲームのグラフィックス描画
    
- 動画編集・エフェクト処理
    
- Stable Diffusionなどの画像生成AI
    
- ローカルLLMの推論処理
    

なお、NVIDIAのGPUには、AIで使用される行列演算を高速化する**Tensor Core**も搭載されている。

したがって、GPUもAI処理に十分対応できる。

---

## 4. TPU：Tensor Processing Unit

### TPUとは

TPUは、Googleが開発したAI・機械学習向けの専用プロセッサーである。

正式名称は**Tensor Processing Unit（テンソル処理装置）**である。

特にニューラルネットワークで大量に実行される行列演算を効率的に処理するために設計されている。

### Tensor（テンソル）とは

テンソルとは、数学における概念の一つであり、機械学習では一般的に**複数の次元を持つ数値データ**として扱われる。

例えば、画像は次のような構造で表現できる。

```
画像データ

高さ × 幅 × 色

1080 × 1920 × 3
```

これはRGB画像を3次元の数値配列として表現した例である。

AIは、このような大量の数値データを利用して計算を実行する。

### 特徴

- AI・機械学習向けに設計されている。
    
- 大規模な行列演算を効率的に処理できる。
    
- 対応する処理では高い電力効率が期待できる。
    
- GPUと比較して対応する用途やソフトウェア環境に制約がある。
    

### 処理のイメージ

```
TPU

入力行列A       入力行列B
┌───────┐     ┌───────┐
│ 1 2 3 │     │ 7 8 9 │
│ 4 5 6 │     │ 3 2 1 │
└───────┘     └───────┘
      │             │
      └──────┬──────┘
             ↓
       行列の掛け算
             ↓
       計算結果の行列
```

TPUには、行列の掛け算を高速に実行するための専用演算器（MXU）が搭載されている。

AIでは膨大な行列演算が繰り返されるため、この処理を効率化することが重要である。

### 具体例

Google Cloud TPUは、Google Cloud上で利用できるAI向け計算リソースである。

大規模言語モデルの学習や推論などに利用される。

ただし、TPUがすべてのAI処理でGPUより高速というわけではない。

処理内容、モデル構造、ソフトウェアへの対応状況によって性能や効率は変化する。

## 5. 3種類のプロセッサーを比較

### 5.1 処理方法の違い

|処理内容|CPU|GPU|TPU|
|---|---|---|---|
|OSの実行|◎|×|×|
|複雑な条件分岐|◎|△|△|
|大量の並列計算|○|◎|◎|
|ゲームの3D描画|△|◎|×|
|AIの学習|△|◎|◎|
|AIの推論|○|◎|◎|
|大規模な行列演算|△|◎|◎|
|一般的なアプリ操作|◎|△|×|

※評価は一般的な用途への適性を表す。実際の性能比較ではない。

### 5.2 役割を例えると

3種類を工場に例えると、以下のようになる。

**CPU：多種多様な仕事をこなせる熟練作業員**

複雑な判断や、状況に応じた柔軟な作業が得意である。

**GPU：大量の作業員が並ぶ生産ライン**

同じ種類の作業を大量に並列処理することが得意である。

**TPU：特定製品を製造する専用工場**

限られた種類の作業を、専用設備によって効率的に処理する。

この例えから分かるように、3種類は単純な上下関係ではなく、役割が異なる。

## 6. AIではGPUとTPUのどちらが優れているのか

AIの処理には、GPUとTPUの両方が利用されている。

ただし、必ずしもTPUの方が優れているわけではない。

### GPUの利点

- 画像処理からAIまで幅広い用途に対応できる。
    
- CUDAなどの開発環境が普及している。
    
- 多くのAIモデルやソフトウェアが対応している。
    
- 個人でもGeForceなどを利用してAIを実行できる。
    

### TPUの利点

- AI向けの行列演算に特化している。
    
- 対応する処理では高い電力効率が期待できる。
    
- Google Cloudを通じて大規模なAI計算に利用できる。
    
- 大規模なAIインフラで、GPU以外の選択肢となる。
    

### なぜTPUが注目されているのか

AIの普及によって、大規模なデータセンターでは膨大な計算能力が必要になっている。

特に問題となるのが、以下のコストである。

1. 半導体の導入費用
    
2. 計算に必要な電力
    
3. 冷却設備の運用費用
    
4. AIサービスの継続的な推論コスト
    

TPUは、対応するAI処理の効率を高めることで、これらの負担を軽減できる可能性がある。

ただし、実際の費用対効果は、ハードウェア価格や電力消費だけでなく、ソフトウェアの最適化や稼働率などにも左右される。

---

## 7. まとめ

CPU・GPU・TPUは、いずれも計算を実行する半導体であるが、設計目的が異なる。

- **CPU：汎用性と柔軟性を重視したプロセッサー**
    
- **GPU：大量の並列計算を得意とするプロセッサー**
    
- **TPU：AI向けの行列演算に特化したプロセッサー**
    

GPUは画像処理のために開発されたが、現在ではAIの主要な計算基盤としても使用されている。

TPUは、そうしたAI処理をさらに専門化した半導体である。

ただし、TPUがGPUを完全に置き換えるわけではない。

**CPU・GPU・TPUは、それぞれ異なる処理に適性を持ち、用途に応じて使い分けられる関係にある。**
