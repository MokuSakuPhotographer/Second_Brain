# D-109M

#ホームシアター #スピーカー #サラウンドスピーカー #天井スピーカー #Onkyo

## 基本情報

- **メーカー**: Onkyo
- **製品名**: D-109M
- **カテゴリ**: サラウンドスピーカー / 小型ブックシェルフスピーカー
- **所有状況**: 所有
- **運用メモ**: 依頼上は天井スピーカー・サラウンドスピーカー。製品自体は一般的な小型サラウンドスピーカー。

## 仕様

| 項目 | 内容 |
|---|---|
| 形式 | 2ウェイ・バスレフ型 |
| 用途 | サラウンド / 天井スピーカー候補 |
| ウーファー | 8cm N-OMFコーン x 1 |
| ツイーター | 2cmバランスドーム x 1 |
| 周波数特性 | 70Hz-80kHz |
| クロスオーバー周波数 | 8kHz |
| 最大入力 | 40W |
| 定格インピーダンス | 6Ω |
| 出力音圧レベル | 81dB/W/m |
| 端子 | バナナプラグ対応 |
| サイズ | 102 x 175 x 129mm |
| 重量 | 1.2kg |
| カラー | ブラック |

## 導入目的

- ホームシアターのサラウンドまたは天井側スピーカーとして使う候補。
- [[TX-NR646]] のサラウンド出力、またはAtmos用トップ/ハイトチャンネルに割り当てる運用を想定。
- 小型・軽量のため、設置自由度を優先したサラウンド構成に向く。

## 接続メモ

| 接続先 | 役割 |
|---|---|
| [[TX-NR646]] | サラウンド / ハイト出力 |
| [[D-509E]] | フロントL/R |
| [[D-509C]] | センター |
| [[SL-A251]] | 低域補強 |

## 注意点

- 低域は70Hzからのため、AVアンプ側で小型スピーカー扱いにし、サブウーファーへ低域を逃がすのが無難。
- 天井スピーカーとして使う場合は、落下防止と固定方法を必ず確認する。
- 定格感度81dB/W/mなので、他スピーカーとの音量補正が必要。

## 調査メモ

- 価格.com、AV Watch、販売店仕様で、70Hz-80kHz、6Ω、40W、81dB/W/m、102 x 175 x 129mm、1.2kgを確認。
- 製品分類はサラウンドスピーカーであり、天井専用スピーカーではない。
