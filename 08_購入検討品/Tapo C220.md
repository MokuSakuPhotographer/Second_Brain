## 導入目的

- [[自律対話型機械ペット構築計画]] のカメラ増設用として、部屋全体を見渡す固定カメラ候補。
- パンチルト機能により、1台で複数方向を確認しやすくする。
- RTSPとONVIFに対応しているため、Tapoアプリ以外の監視・録画・実験環境との連携余地がある。
- 2K QHD 4MP解像度とスターライトセンサー対応により、室内の様子を確認しやすい。

## 購入検討メモ

| 観点 | メモ |
|---|---|
| 良い点 | パンチルトで部屋全体を見渡しやすい |
| 良い点 | 2K QHD 4MPで、室内見守り用途として解像度に余裕がある |
| 良い点 | RTSP / ONVIF対応のため、外部システム連携の検討がしやすい |
| 良い点 | ペット検知、人物検知、泣き声検知など、室内監視向きの検知項目が多い |
| 良い点 | microSD最大512GB対応で、ローカル保存を選べる |
| 注意点 | 2.4GHz Wi-Fiのみ対応。設置場所で通信が安定するか確認する |
| 注意点 | 屋内用であり、屋外・水回りには向かない |
| 注意点 | PCからの公式視聴は不可とされ、基本はスマートフォンアプリTapoでの利用 |
| 注意点 | microSDカードは別売り。推奨・非推奨カードの条件を購入前に確認する |
| 注意点 | ベータ検知機能は精度や仕様変更の可能性があるため、主要用途にしすぎない |
