# 搭載機能

## 1. カメラ・人物検出

### RTSP映像取得

- Tapo C200のRTSP映像を取得
- OpenCVでフレーム処理
- RTSP切断時の再接続処理あり
- 停止・再起動時にRTSPを安全解放

### 人物検出

- YOLOv8nを使用
- 人物クラスのみ検出
- 検出信頼度しきい値あり
- ROIによる検出範囲制限あり
- 小さすぎる人物候補を除外

### 入退室判定

| 状態 | 内容 |
|---|---|
| 入場候補 | 人物検出が一定時間安定した状態 |
| 在席 | 入場判定が確定した状態 |
| 離席候補 | 人物検出が途切れた状態 |
| 離席 | 一定時間人物が見えない状態 |
| 外出 | 長時間不在状態 |

### 安定化処理

- 存在スコア方式
- 入場確認秒数あり
- 離席確認秒数あり
- 状態変化クールダウンあり
- PTZ移動直後は人物未検出を離席扱いしない

---

## 2. Tapo C200 PTZ制御

### 手動首振り

- 左へ向く
- 右へ向く
- 上へ向く
- 下へ向く
- 斜め移動
- 停止
- ホームへ戻る
- 現在位置をホーム保存
- ホーム上書き確認
- PTZ状態確認

### ホーム制御

- C200本体の絶対座標ではなく、ソフトウェア上の移動履歴でホームを管理
- ホーム位置は `data/ai_pet_ptz_state.json` に保存
- 再起動後もホーム保存状態を保持

### 自律巡回

- 通常巡回
- 右方向への段階移動
- 左方向への復帰
- 巡回後ホーム復帰
- 巡回中ログ出力
- 会話直後・手動操作直後は一時停止

### 在席中キョロキョロ

- 人物検出中に小さく視線移動
- 15〜60秒程度のランダム間隔
- 移動後に人物検出猶予を付与
- 巡回とは独立して動作可能

### マスター探索

- 離席後にマスターを探す動作
- 寂しさ、元気、離席時間で発火判定
- 探索開始・終了時の発話あり
- 最大探索時間あり
- クールダウンあり

---

## 3. ムード連動PTZ

| 条件 | モード | 動き |
|---|---|---|
| 拗ね・不安 | 控えめ巡回 | 低速、低頻度 |
| 疲れ・眠い | 低活動モード | あまり動かない |
| 寂しさ高め | 寂しさ連動探索 | 探す動きが増える |
| 好奇心高め | 好奇心連動巡回 | 見回り頻度が上がる |
| 嬉しい・安心 | 軽い見回り | 穏やかに巡回 |
| 通常 | 落ち着き巡回 | 低頻度で安定 |

# 音声機能

## 4. 音声入力

### マイク入力

- Realtek系マイクを優先
- PortAudio / sounddevice使用
- 入力デバイスの自動選択
- サンプルレート自動フォールバック
- 音量監視
- dBFSによる簡易VAD

### 発話チャンク化

- 発話開始しきい値あり
- 無音終了判定あり
- プリロールあり
- 最小・最大チャンク秒数あり
- WAVとして一時保存

### 音声認識

- faster-whisper small
- 日本語認識
- CPU int8推論
- CUDA失敗時はCPU退避
- 認識品質メタデータを本体へ渡す

### TTS自己音声対策

- シエルが話している間はマイク入力を無視
- 再生終了直後にも短時間ガード
- 自己発話のループ会話を防止

---

## 5. 名前呼び反応

### 反応する呼び名

- シエル
- しえる
- シェル
- シェール
- 消える
- CL
- Ciel
- ciel

### 挙動

- 名前だけ呼ばれると定型応答
- 名前呼び後、5〜10秒程度の受付待機
- 名前と要件を同時に話した場合は要件を優先
- 現設定では名前呼びなしの音声も会話へ渡す

---

## 6. 音声コマンド

| 音声 | 処理 |
|---|---|
| 止まって / とまって | 安全停止 |
| 起動して / きどうして | 起動済み応答 |
| 再起動して / さいきどうして | 安全再起動 |
| こっち向いて / こっちむいて | ホーム方向へ向く |
| 巡回して / じゅんかいして | 自律巡回開始 |
| 静かにして / しずかにして | 自律発話ミュート |
| 話して / はなして | 自律発話再開 |

### 安全判定

- 完全一致のみ実行
- 類似一致は実行せず破棄
- 信頼度が低い音声認識結果は破棄
- 停止・再起動はより高い信頼度を要求
- 音声が短すぎる・長すぎる場合も破棄

# Topic Fatigue

## 18. 話題疲労制御

- 同じ話題の繰り返しをスコア化
- 自律発話ごとに疲労加算
- 同じ話題の連続で追加加算
- 時間経過で回復
- 高疲労話題はプロンプトで避ける
- しきい値超過時は保険文へ切替

| しきい値 | 意味 |
|---|---|
| 45 | 警告 |
| 70 | 抑制 |
| 90 | 強抑制 |

# 弱点・未完成部分

## 安全面

- Discord Botトークンが平文で入っている
- カメラ認証情報が平文で入っている
- IP、チャンネルID、モデル名などがコード直書き
- 外部共有やGit管理には危険

## 保守性

- `ai_pet_brain.py` が巨大
- 機能境界がかなり混ざっている
- 設定、状態、処理、プロンプトが密結合
- 不具合時に原因箇所を探しにくい
- 小変更でも副作用が出やすい

## 安定性

- 外部依存が多い
  - Tapo C200
  - RTSP
  - ONVIF
  - Ollama
  - GPT-SoVITS
  - VOICEVOX
  - Discord
  - faster-whisper
- どれか1つが落ちると挙動が複雑になる
- テストコードが見当たらない
- 起動順や外部サーバー状態に依存する

## 運用性

- 設定ファイル化が途中
- 一部JSONは将来用または現行未使用
- ログ・デバッグ音声・一時音声が増えやすい
- バックアップと現行ファイルの境界を知らないと混乱しやすい

# 総評

> [!important]
> このプロジェクトは、単なるカメラ監視Botではなく、かなり本格的な「生活空間内AIペット」になっている。

現時点では、体験面の完成度は高い。  
特に、入退室、寂しさ、好奇心、記憶、首振り、音声が連動している点はかなり良い。

ただし、ソフトウェアとしてはまだ荒い。  
大きな単一ファイルに多くの責務が集まっており、認証情報も直書きされているため、完成品というよりは「かなり育った個人用実験機」という評価が近い。

最終的な評価は以下。

| 観点 | 評価 |
|---|---|
| 発想 | 非常に良い |
| 機能量 | 非常に多い |
| 個人運用 | 実用圏内 |
| 長期安定性 | まだ不安あり |
| 保守性 | 要改善 |
| セキュリティ | 要改善 |
| 完成品度 | 中盤〜後半 |
