# 「福井駅駅」という駅と「駅駅」という熟語

## 福井駅駅は実在するのか

福井県福井市には、「福井駅駅」と表記される福井鉄道福武線の停留場が存在する。

ただし、正式な駅名は「福井駅（ふくいえき）」であり、「福井駅駅」ではない。駅名そのものに「駅」という漢字が含まれているため、駅を示す接尾辞を付けると「福井駅駅」となる。

|鉄道会社|駅名|接尾辞を付けた表記|
|---|---|---|
|JR西日本|福井|福井駅|
|ハピラインふくい|福井|福井駅|
|えちぜん鉄道|福井|福井駅|
|福井鉄道|福井駅|福井駅駅|

実際に、NAVITIMEでは福井鉄道の停留場を「福井駅駅」と表記している。

## 福井駅駅が誕生した経緯

福井鉄道の停留場は、かつて「福井駅前」という名称であった。

2016年3月27日、福井鉄道の線路が福井駅西口広場まで延伸されたことに伴い、停留場が移設され、「福井駅」に改称された。

|項目|内容|
|---|---|
|正式名称|福井駅|
|読み方|ふくいえき|
|旧名称|福井駅前|
|運営会社|福井鉄道|
|路線|福武線|
|駅番号|F22|
|改称日|2016年3月27日|

「福井駅駅」という表記によってJRなどの福井駅と区別することは可能であるが、区別すること自体を目的として改称されたという根拠は確認されていない。

## 「駅駅」という熟語

鉄道とは別に、「駅駅」という熟語も存在する。

| 項目   | 内容          |
| ---- | ----------- |
| 表記   | 駅駅          |
| 読み方  | えきえき        |
| 旧字体  | 驛驛          |
| 意味   | 盛んなさま       |
| 掲載辞典 | 平凡社『普及版 字通』 |

古典漢語に由来する熟語であり、現代日本語ではほとんど使用されない。

中国の古典『詩経』の「周頌・載芟」にも、次の表現が登場する。

> 驛驛其達

農作物が盛んに芽を出し、成長する様子を表している。

この熟語は、現代の鉄道における「駅」とは意味的に無関係である。

## 畳語（じょうご）

「駅駅」のように、同じ語や形態素を繰り返すことで意味を形成する語を、**畳語（重言・重畳語）** という。

状態や程度、反復、複数性などを表現するために用いられる。

|畳語|読み方|意味|
|---|---|---|
|駅駅|えきえき|盛んなさま|
|粛々|しゅくしゅく|静かで厳かなさま|
|淡々|たんたん|あっさりとしたさま|
|悠々|ゆうゆう|ゆとりのあるさま|
|刻々|こくこく|時間の経過とともに|
|洋々|ようよう|広々としているさま|
|堂々|どうどう|威厳のあるさま|
|延々|えんえん|長く続くさま|

なお、「々」は踊り字の一種であり、直前の漢字を繰り返すことを示す記号である。

## まとめ

- 「福井駅駅」と表記される停留場は実在する。
    
- 正式な駅名は「福井駅」であり、接尾辞の「駅」を加えると重複する。
    
- 2016年の福井駅西口広場への延伸・移設に伴い、「福井駅前」から改称された。
    
- 鉄道とは無関係に、「盛んなさま」を意味する「駅駅（えきえき）」という熟語も存在する。
    
- 熟語としての「駅駅」は、畳語の一種である。
    

駅名と接尾辞の組み合わせによって偶然生じた文字の重複が、古典漢語に由来する独立した熟語と一致している興味深い事例である。
