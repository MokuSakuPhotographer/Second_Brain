# 美容師が「髭」、「眉」を剃る行為は違法


## なぜ違法？

髭剃りや眉剃りの定義は「理容」とされ、「理容師免許」を持つ者のみが業として行える。

「美容師法」にはカミソリで皮膚に直接刃物を当てる「顔剃り」の権限は明記されていない。

衛生・安全面から刃物を扱う高度な技術や知識が必要になるため、無免許での施術は法律違反となる。

## 「美容師」と「理容師」の違い

|  | 業務内容 | 定義 |
| --- | --- | --- |
| 美容師 | パーマ・カラー・セット・メイク・着付けなど、**美しくする行為** | **美容師法**による「美容」 |
| 理容師 | カット・顔、髭剃りなど、**身だしなみを整える行為** | **理容師法**による「理容」 |

## どこまでなら許されるのか

- 美容師ができるのは「眉毛カット（ハサミ・トリマー）」「毛抜きによる形調整」「アイブロウメイク等のアドバイス」まで。
- **「カミソリ」**による眉剃り・顔剃り・髭剃りは美容師には認められていない。
- 例外として、メイクアップ目的でごく軽い産毛の処理は地域や状況によって認められる場合もあるものの、基本は理容師のみが施術可能と考えた方が安全。

美容師がカミソリで髭や眉を剃ることは原則違法だが、眉毛のカットやメイクは美容師の業務範囲。
