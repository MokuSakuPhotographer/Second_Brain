# シエル｜Googleカレンダー交通情報連携

## 目的

Googleカレンダーの予定通知に交通状況を反映し、渋滞による遅延を考慮した最適な出発時刻をシエルが提案できるようにする。

## 採用API

**TomTom Orbis Routing API v3**

- 日本国内の道路交通情報に対応
    
- リアルタイムの交通状況を考慮した所要時間を取得可能
    
- 過去の交通傾向を利用した所要時間予測に対応
    
- 月20,000リクエストの無料枠あり（利用条件は導入時に再確認）
    

公式ドキュメント：  
[https://docs.tomtom.com/routing-api/documentation/tomtom-orbis-maps/v3/calculate-route](https://docs.tomtom.com/routing-api/documentation/tomtom-orbis-maps/v3/calculate-route)

## 推奨実装フロー

1. **Googleカレンダー**
    
    - 予定日時と目的地を取得
        
    - 目的地が未設定の場合は交通情報の確認を省略
        
2. **TomTom Routing API**
    
    - 登録済みの出発地点と予定の目的地を指定
        
    - 交通状況を考慮した移動時間を取得
        
    - 通常の移動時間との差分を算出
        
3. **Ciel Core**
    
    - `予定開始時刻 − 予測移動時間 − 余裕時間` で推奨出発時刻を計算
        
    - 渋滞による遅延が予測される場合、早めの出発を提案
        
4. **既存の通知システム**
    
    - 算出結果を既存のGoogleカレンダー通知に追加
        
    - 必要に応じてDiscordなどへ通知
        

## 交通情報の確認タイミング

|タイミング|処理内容|
|---|---|
|前日|過去の交通傾向から所要時間を予測|
|当日・出発前|リアルタイム交通情報を再取得|
|大幅な遅延検出時|推奨出発時刻を更新して通知|

## 通知例

> 明日は14:00から予定があります。
> 
> 通常の移動時間は30分ですが、交通状況により35分かかる見込みです。
> 
> 通常より5分早い、13:25までの出発を推奨します。

## 実装方針

- 既存のGoogleカレンダー連携・通知処理を維持する
    
- TomTom連携を独立した交通情報取得モジュールとして追加する
    
- API障害時は交通情報なしの通常通知に切り替える
    
- 無料API枠の消費を抑えるため、必要な予定のみ交通情報を取得する
    
- 本運用前に日本国内の実際の経路で予測精度を検証する
    

**最終方針：既存のカレンダーリマインダー機能を拡張し、TomTom APIによる交通状況連動型の出発時刻提案を実装する。**
