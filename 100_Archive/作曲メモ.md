# Auditionでミックス

- ミックストラックで各パートを読み込み
  - **最初に「中心トラック」を決める**

    - ボーカル曲 ：ボーカル

    - インスト ：ドラム or ベース
  - その中心のトラックを**レベルメーターで -6dBFS〜-10dBFS** くらいに設定

    （ピークメーターではなく、**平均値（RMS）** で判断）

    | 表示 (dBFS) | VUメーター的な感覚 |
    | --- | --- |
    | -6 dBFS 付近 | やや大きめ（パンチが出る） |
    | -10 dBFS 付近 | おおよそ 0 VU（標準的な平均音量） |
    | -12 dBFS 以下 | やや小さめ（静かめのトラック） |
  - 振幅統計でスキャンし、**平均RMSが-18db～-14db前後**になっているか確認
  - 他のパートを **“聴感”で中心に対して足していく。**

- 各パートの音量を決める

  | トラック | 目安RMS (相対) | 備考 |
  | --- | --- | --- |
  | ボーカル | 0dB（基準） | 最も前に出す。常に聴き取れるレベルに。 |
  | スネア | -3〜-6dB | アタック感が失われないように。 |
  | キック | -4〜-6dB | ボーカルと同等の存在感。ただし被らせない。 |
  | ベース | -6〜-8dB | キックと一体化する程度に。低域を支える。 |
  | ハイハット／シンバル | -10〜-12dB | 上物。空気感を作る程度で十分。 |
  | ギター／ピアノ | -8〜-10dB | ボーカルを覆わず、ステレオを埋めるように配置。 |
  | パッド／ストリングス | -12〜-16dB | 背景。存在を感じる程度。 |
  | FX／リバーブリターン | -18〜-22dB | 薄く空気感を与えるレベル。 |

- 各パートのパンを決める
  - 以下の表が指標

  | パート | 推奨パン位置 | 理由／ポイント |
  | --- | --- | --- |
  | キック | C（センター） | リズムの基準。定位がブレると全体が不安定に。 |
  | スネア | C（センター） | リズムの軸。わずかに±2程度ならOKだが基本は中央。 |
  | ベース | C（センター） | 低域は定位が取りづらいので中央固定。 |
  | ボーカル | C（センター） | 最も重要な要素。コーラスは左右に広げて主旋律と分離。 |
  | コーラス（ハモリ） | L/R 30〜60 | メインを包むように広げる。シンメトリー配置が理想。 |
  | リードギター | L/R 10〜30 | メインボーカルを邪魔しない範囲。リズムギターと対称配置。 |
  | リズムギター（2本） | L100 / R100 または L80 / R80 | 壁を作るように左右に広げる。厚みと広がりを担当。 |
  | ピアノ／キーボード | L/R 20〜60 | ギターとのバランスを見ながら中間域を埋める。 |
  | シンセパッド／ストリングス | L/R 50〜100 | 空間の広がり要素。中心から外側にふわっと置く。 |
  | ハイハット | L10〜L40（またはR） | ドラムセットの実際の位置関係を参考に。 |
  | ライドシンバル | R20〜R50（またはL） | ハイハットの反対側に配置。左右のバランスを取る。 |
  | タム | L50〜R50（順に配置） | ドラムの自然な回転方向に合わせて配置。 |
  | パーカッション | L/R 30〜90 | 楽曲に応じて隙間を埋める。主楽器を邪魔しない位置。 |
  | FX（リバーブ・空間系） | ステレオワイド（L/R 100） | 空気感・奥行きを作る。モノラル成分は小さめに。 |

  ### ステレオの「重心」を常に意識する

  - 全トラックを再生しながら、頭の中で“左右どちらが重いか”を感じ取る。
  - 偏って感じたら、反対側に別の楽器を配置するか、リバーブでバランスを取る。
    - 視覚的メーター（Stereo Field Analyzer / Goniometer）を併用するとわかりやすい。
  - 周波数帯で分ける意識

  | 帯域 | 推奨配置 | 理由 |
  | --- | --- | --- |
  | 低域（〜150Hz） | センター固定 | モノラル互換の確保・安定感 |
  | 中域（150〜2kHz） | 左右へ分散 | 音の分離・明瞭感アップ |
  | 高域（2kHz〜） | 広めに配置 | 空気感・抜けの演出 |

### “L/Rに対称性を持たせる”と全体が安定する

- Lにギター、Rにピアノ

- Lにコーラス1、Rにコーラス2　など

- パラメトリックEQで各パートを調整

- コンプレッサーで各パートを調整

- リバーブで各パートの空間づくり

# Auditionでマスタリング

- エフェクトからノーマライズをかける

  ノーマライズ：-1db

  DC補正オフセット：0.3%

- エフェクトからスペシャルにあるマスタリングをかける

  **Adobe Audition「マスタリング」設定例（Rock向け）**

  |  |  |  |
  | --- | --- | --- |
  | 項目 | 推奨設定値 | 説明 |
  | リバーブ | 8～12% | 小さめのホール感を追加。ドライすぎると平坦になるため、軽く空間を。 |
  | エキサイター | 15~20% モード：チューブ | 高域を華やかに。ギターやボーカルが抜けやすくなる。 |
  | 増幅 | +20〜30% | ダイナミクスを抑え、全体を締める。特にドラムやギターをまとめたい場合に有効。 |
  | リミッタ | 20～30% | クリップ回避＋配信用に安全なレベル。 |

  ---

  **イコライザー（EQ）設定例**

  | バンド | 周波数 | Q値 | ゲイン | 意図 |
  | --- | --- | --- | --- | --- |
  | ローカット | 30Hz | 6 | -3db | ベース・ドラムの明瞭化 |
  | 中域ピーキング | 800Hz | 1 | -1.5db | ボーカルとギターの密集対の整理 |
  | ハイシェルフ | 12000Hz | 6 | +2~3db | 空気感と抜け感を付与 |

  **補足調整ポイント**
  ギターが強すぎる場合 → 2.5〜3kHzあたりを -1dB 下げる
  ボーカルをもう少し前に出したい場合 → 5kHzあたりを +1dB 上げる
  ドラムが引っ込みがちなら → 80〜120Hz を +1dB
