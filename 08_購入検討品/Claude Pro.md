# Claude Pro

#購入検討 #AI #Claude #サブスクリプション

## 基本情報

- **提供元**: Anthropic
- **サービス名**: Claude Pro
- **カテゴリ**: AIチャットサービス / サブスクリプション
- **所有状況**: 購入検討
- **公式アップグレードURL**: https://claude.ai/upgrade

## 仕様

| 項目 | 内容 |
|---|---|
| 月額 | $20/month |
| 年額 | $200/year |
| 対象 | 個人向けClaudeチャット体験 |
| 使用量 | Freeより少なくとも5倍のセッション使用量 |
| 制限リセット | セッション使用量は5時間ごとにリセット |
| 追加制限 | 週次・月次・モデル別・機能別の制限が適用される場合あり |
| 優先アクセス | 高トラフィック時の優先アクセス |
| モデル選択 | モデルセレクター利用可 |
| Projects / Knowledge | 利用可 |
| Claude Code | アクセスあり |
| API利用 | Claude ConsoleのAPI利用料は含まれない |
| 上位候補 | Max 5x、Max 20x |

## 導入目的

- [[購入検討品DB]] では、#ChatGPT の #Codex が使えることが分かったため優先度は低め。
- ChatGPT / Codexで足りない場合の比較用AIサービスとして検討。
- 長文読解、別視点でのレビュー、文章作成、調査の補助に使えるか確認する。

## 購入検討メモ

| 観点 | メモ |
|---|---|
| 良い点 | Freeより使用量が多く、混雑時の優先アクセスがある |
| 良い点 | Projects / Knowledgeが使えるため、継続的な文脈管理に向く |
| 良い点 | Claude Codeアクセスが含まれる |
| 注意点 | API利用料は含まれない |
| 注意点 | 使用量は固定無制限ではなく、入力長・添付ファイル・モデル・機能で変動する |
| 注意点 | 価格・利用制限は変更される可能性がある |
| 現状判断 | Codexで十分な場面が多いため、優先度は低め |

## 調査メモ

- Anthropic公式ヘルプでProの月額、年額、主な機能、使用量制限を確認。
- 価格・制限は変わり得るため、課金直前に公式アップグレード画面で日本向け表示を確認する。
