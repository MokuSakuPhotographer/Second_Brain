# トラベルミン

> [!warning] 製剤確認が必要
> 以下は**医療用「トラベルミン配合錠」**として作成した。市販のトラベルミンには別の製剤・成分もある。薬袋やPTPシートで正式な製剤名を確認する。

## 薬の基本情報

| 項目 | 内容 |
|---|---|
| 想定製剤 | トラベルミン配合錠（医療用） |
| 有効成分 | ジフェンヒドラミンサリチル酸塩＋ジプロフィリン |
| 分類 | 鎮暈薬、抗ヒスタミン作用を含む配合剤 |
| 主な効能・効果 | 乗り物酔い・メニエール症候群に伴う悪心、嘔吐、めまい |
| 現在の服薬 | **朝1錠・昼1錠・晩1錠**（本人申告） |
| 製品名・規格の現物照合 | 未確認 |

## 作用

ジフェンヒドラミン成分が内耳の刺激に伴う吐き気・めまいを抑える。ジプロフィリンを含む配合剤である。乗り物酔い以外のめまいに使われる場合もある。

## 主な副作用

- **眠気、倦怠感、頭重感、めまい**。
- **口の渇き**、悪心・嘔吐、下痢。
- 動悸、発疹、神経過敏、頭痛など。

## 注意事項

- 抗コリン作用に関連し、閉塞隅角緑内障・尿路閉塞などでは禁忌となる。
- アルコールや中枢神経抑制作用のある薬との併用で眠気・反応低下が増すおそれ。
- **アルプラゾラムとの併用は眠気・注意力低下に特に注意する。** 添付文書は運転など危険な機械操作について警告している。
- ジプロフィリンを含むため、カフェインなど他のキサンチン系薬剤との併用にも注意が必要。
- 毎日服用している目的と継続期間を、処方医・薬剤師と定期的に確認する。
