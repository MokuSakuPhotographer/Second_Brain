# ChatGPT_KB

Deep Researchに読ませるための軽量ナレッジベースです。

## 使い方

GitHub上でDeep Researchに読ませる時は、Vault全体ではなく、この `ChatGPT_KB` フォルダを優先的に参照させてください。

## 構成

- Camera: 撮影機材・レンズ・ライティング・撮影ワークフロー
- Media: アニメ・ドラマ・好みの傾向
- Profile: このKBの使い方と全体マップ

## 注意

これは詳細DBではなく、ChatGPT用の要約レイヤーです。
詳細情報は元のObsidianノートに残し、ここには「検索に必要な要約」だけを置く運用が最適です。
