# 起動手順

## 1. GPT-SoVITS WebUIを起動

まず **GPT-SoVITS WebUI** を起動します。  
`api_v2.py` ではなく、WebUIです。

起動後、ブラウザでここを開ける状態にします。

```
http://localhost:9872
http://localhost:9972
```

ここが開けない場合、シエルとラファエルのGPT-SoVITS音声は動きません。

---

このファイルが存在するか確認します。

## 4. 常駐ランチャーを起動

次に **シエル常駐ランチャー** を起動します。


# 完全起動順まとめ

```
1. GPT-SoVITS WebUIを起動
2. http://localhost:9872 と http://localhost:9972 が開けることを確認
3. 参照音声ファイルが固定パスにあることを確認
4. 必要ならWebUIで一度手動合成
5. シエル常駐ランチャーを起動
6. ランチャー経由で安定版brainが起動
```

---

# 停止手順

停止は **起動と逆順** です。

```
1. シエルを停止
2. 常駐ランチャーを停止
3. GPT-SoVITS WebUIを停止
```

## Discordから停止する場合

シエルに以下を送ります。

```
停止して
```

または、

```
システム停止
```

この場合、シエル本体は安全停止します。

常駐ランチャーが残る構成の場合は、ランチャーも必要に応じて手動で閉じます。

---

# 再起動手順

## シエルだけ再起動する場合

GPT-SoVITS WebUIは起動したままでOKです。

```
1. Discordで「再起動して」
2. シエル本体が終了コード20で終了
3. 常駐ランチャーが安定版brainを再起動
```

この場合、GPT-SoVITS WebUIは触らなくていいです。

---

## GPT-SoVITSも含めて全部再起動する場合

```
1. シエルを停止
2. 常駐ランチャーを停止
3. GPT-SoVITS WebUIを停止
4. GPT-SoVITS WebUIを起動
5. http://localhost:9872 を確認
6. 常駐ランチャーを起動
7. 安定版brainが起動
```

---

# PC再起動後の手順

PCを再起動した後は、この順番です。

```
1. GPT-SoVITS WebUIを起動
2. http://localhost:9872 が開けることを確認
3. 必要ならWebUIで「おかえり、マスター。」を手動合成
4. シエル常駐ランチャーを起動
```

---

# やってはいけない順番

これは避けてください。

```
シエル起動
↓
GPT-SoVITS WebUI起動
```

理由は、シエルが先に `localhost:9872` へ接続しようとして失敗するためです。

また、停止時にこれも避けます。

```
GPT-SoVITS WebUI停止
↓
シエル稼働中
```

この状態だと、シエルのGPT-SoVITS音声生成が失敗します。

---

# 異常時の確認先

## 音声が出ない

まず確認する場所：

```
http://localhost:9872
```

WebUIが開けるか確認します。

---

## 参照音声アップロード失敗

確認する場所：

```
C:\Users\mokus\Desktop\GPT_Create\gpt_sovits_ref\Ishikawayui_ref.wav
```

このwavが存在するか確認します。

---

## 音が変

確認する場所：

```
gpt_sovits_debug
```

ここに保存される `ciel_gradio_...wav` を直接再生します。  
このwav自体が変ならGPT-SoVITS生成側、wavが正常なら再生側の問題です。

---

# 最終運用形

```
通常起動:GPT-SoVITS WebUI → シエル常駐ランチャー

通常停止:シエル → 常駐ランチャー → GPT-SoVITS WebUIシエルだけ

再起動:Discordで「再起動して」

全部再起動:シエル停止 → ランチャー停止 → WebUI停止 → WebUI起動 → ランチャー起動
```
