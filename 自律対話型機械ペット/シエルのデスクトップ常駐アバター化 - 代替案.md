# シエルのデスクトップ常駐アバター化

> [!NOTE]
> **この手法はCharacterVariationGeneratorでうまく作成ができなかった場合の代替案とする。**

## Qwen Image Edit 2511から完成まで

## 目的

シエルを単なる音声・テキストAIではなく、**Windowsデスクトップ上に常駐する視覚的なAIアバター**として表示する。

最終形では、シエルが画面端に常駐し、内部状態に応じて表情が変化する。

想定する動作は以下。

- 通常時は落ち着いた表情で待機
    
- 会話中は口パク
    
- 数秒おきに自然に瞬き
    
- 良い結果なら笑顔
    
- 想定外の事象では驚き
    
- エラー発生時は困り顔
    
- 深夜などは眠そうな表情
    
- AI処理中は「考え中」の状態を表示
    
- シエル本体とは独立した軽量プロセスとして常駐
    
- 将来的には通知、Obsidian検索、PC操作などの状態とも連動
    

最初からLive2Dや3Dモデルを導入するのではなく、**PNG差分を利用した軽量2Dアバター**として構築する。

---

# 1. 最終構成

完成時のシステムは以下の構造とする。

```
┌─────────────────────────┐
│       シエル本体         │
│                         │
│ ローカルLLM             │
│ TTS                     │
│ Obsidian                │
│ PC操作                  │
│ 各種センサー            │
└───────────┬─────────────┘
            │
            │ WebSocket / localhost API
            ↓
┌─────────────────────────┐
│    Avatar Controller    │
│                         │
│ emotion                 │
│ speaking                │
│ thinking                │
│ blink                   │
│ notification            │
└───────────┬─────────────┘
            ↓
┌─────────────────────────┐
│    Desktop Avatar UI    │
│      PySide6 / Qt       │
│                         │
│ PNG差分表示             │
│ 瞬き                    │
│ 口パク                  │
│ 表情切り替え            │
└─────────────────────────┘
```

重要なのは、**シエル本体とアバター表示アプリを分離すること**。

これにより、

- アバターだけ再起動できる
    
- AI処理と表示処理が干渉しにくい
    
- 将来Live2Dなどへ表示部分だけ交換できる
    
- シエル本体を変更してもアバター側への影響が少ない
    

という利点が得られる。

---

# 2. アバター形式は「上半身PNG差分方式」

基本表示は**上半身**とする。

全身ではデスクトップ上で顔が小さくなり、顔だけではアバターとしての存在感や身振りを表現しにくい。

推奨範囲は、

```
頭
↓
胸
↓
腰より少し上
```

程度。

将来的には、

```
通常モード
→ 上半身

省スペースモード
→ 顔だけ

会話モード
→ 上半身を少し拡大
```

のような切り替えも可能。

---

# 3. 最初に用意する表情

初期版では以下の5種類に限定する。

|ID|表情|主な用途|
|---|---|---|
|`neutral`|通常|待機状態|
|`smile`|笑顔|良い結果・通常会話|
|`surprised`|驚き|想定外の結果|
|`troubled`|困り|エラー・処理失敗|
|`sleepy`|眠そう|深夜・低活動状態|

最初から大量の表情を作る必要はない。

システム完成後に、

```
thinking
angry
excited
embarrassed
serious
```

などを必要に応じて追加する。

---

# 4. Qwen Image Edit 2511を使用する理由

シエルの表情差分では、

> 同じ人物の顔・髪型・服装・構図を維持しながら、表情だけ変更する

必要がある。

Qwen-Image-Edit-2511はQwen-Image-Edit-2509の改良版で、キャラクター一貫性や局所編集能力が改善されている。ComfyUI公式側でも2511用テンプレートが提供されている。

そのため、

```
元画像
↓
表情だけ変更
↓
Photoshopで固定画像へ合成
```

という方式に適している。

# 9. シエルの基準画像を作る

ここからが実際のアバター制作工程。

最も重要なのは、

> **すべての表情を同じ基準画像から派生させる**

ことである。

## 基準画像の条件

```
・上半身
・顔が十分大きい
・髪型完成済み
・服装完成済み
・構図完成済み
・照明完成済み
・正面〜軽い斜め向き
・背景透過または単色
```

この画像を、

```
ciel_base_upperbody.png
```

として保存する。

一度基準画像を決定した後は、**身体や構図を再生成しない**。

# 14. 表情別プロンプト

## Neutral

Neutralは基本的に元画像をそのまま使用する。

必要な場合のみ、

```
Keep a neutral and calm facial expression.
Relaxed eyebrows, natural open eyes, and a closed relaxed mouth.
```

を使用する。

---

## Smile

```
Change only the facial expression to a gentle closed-mouth smile.

Slightly soften the eyes and cheeks.
Create a friendly and calm expression.
Keep the smile subtle and natural.
```

大きく口を開ける笑顔にはしない。

後から口パク処理を追加しやすくするためである。

---

## Surprised

```
Change only the facial expression to a mildly surprised expression.

Raise the eyebrows slightly.
Widen the eyes moderately.
Open the mouth only slightly.
Keep the expression natural and not exaggerated.
```

---

## Troubled

```
Change only the facial expression to a slightly troubled expression.

Tilt the eyebrows inward gently.
Soften the eyes.
Give the mouth a subtle worried shape.
Keep the expression restrained and natural.
```

---

## Sleepy

```
Change only the facial expression to a sleepy expression.

Lower the eyelids.
Relax the eyebrows.
Give the mouth a soft and slightly tired expression.
Keep the result gentle and natural.
```

Qwenから出力した顔画像を基準画像の上に配置。

```

# 23. 表情切り替えテスト

5枚を高速で切り替える。

チェックする場所：

```
髪が揺れない
肩が動かない
頭部位置が変わらない
鼻が上下しない
顎が変形しない
服が変化しない
```

**動いてよいのは表情だけ**。

ズレが確認された場合は、再生成より先にPhotoshopのマスク範囲を縮小する。

# 24. 次に瞬き差分を作る

最低限：

```
eyes_open

eyes_closed
```

の3種類。

アニメーション：

```

↓
HALF
↓
CLOSED
↓
HALF
↓
OPEN
```

通常時は数秒ごとにランダムで瞬きさせる。

# 25. 口パク差分を作る

最低限：

```
mouth_closed
mouth_small
mouth_open
```

の3種類。

TTS再生中のみ、

```
closed
↓
small
↓
open
↓
small
↓
closed
```

と切り替える。

本格的な音素解析を行わなくても、TTSの音量レベルを利用して、

```
無音
→ closed

小音量
→ small

大音量
→ open
```

とすれば十分自然に見える。

```

# 29. 常時60fpsにしない

低負荷常駐が目的なので、常時レンダリングは避ける。

推奨：

```
完全待機
→ 画像更新なし

瞬き
→ 必要な瞬間のみ更新

発話中
→ 10〜20fps程度

表情変更
→ 変更時のみ更新
```

PNG差分方式なら、待機中はほぼ静止画像として扱える。

RTX 4090を搭載していても、常駐アバターのためにGPUリソースを継続消費する設計にはしない。

# 31. シエル側の表情判定

重要なのは、LLMに直接、

> 今どのPNGを表示する？

と決めさせないこと。

シエル本体側で状態を限定する。

例：

```
neutral
smile
surprised
troubled
sleepy
```

LLMまたはシステムがこの中から1つだけ選ぶ。

これにより表示制御が安定する。

---

# 32. 状態と表情の基本対応

```
待機
→ neutral

通常会話
→ neutral / smile

ユーザーへの肯定的な結果
→ smile

予想外の結果
→ surprised

エラー
→ troubled

処理失敗
→ troubled

深夜
→ sleepy
```

将来的に、

```
LLM推論中
→ thinking

Obsidian検索
→ thinking

重要通知
→ surprised + !

TTS発話
→ 現在の表情 + mouth animation
```

へ拡張する。

# 33. Obsidianとの連動

シエルがObsidianを検索している場合、

```
emotion = neutral
thinking = true
```

とする。

検索完了：

```
thinking = false
emotion = smile
```

検索結果なし：

```
emotion = troubled
```

とすれば、内部処理が視覚的に理解できるようになる。

# 38. 最終的なゴール

最終的にはシエルを、

```
AI
+
Obsidian外部記憶
+
PC操作
+
音声
+
センサー
+
デスクトップアバター
```

として統合する。

概念的には以下。

```
                 ┌─────────────┐
                 │   マスター   │
                 └──────┬──────┘
                        │
           音声 / テキスト / 操作
                        ↓
              ┌────────────────┐
              │      シエル      │
              ├────────────────┤
              │ Local LLM      │
              │ Memory         │
              │ Obsidian       │
              │ TTS            │
              │ PC Control     │
              │ Sensors        │
              └────────┬───────┘
                       │
                Current State
                       ↓
              ┌────────────────┐
              │ Avatar Engine  │
              ├────────────────┤
              │ Expression     │
              │ Blink          │
              │ Lip Sync       │
              │ Effects        │
              └────────┬───────┘
                       ↓
                Desktop Ciel
```

最終的な目的は、単にキャラクター画像をデスクトップへ表示することではない。

**シエル内部で起きている状態を、アバターの表情・動作として視覚化すること**が本質となる。

これにより、

```
考えている
検索している
話している
困っている
通知したい
待機している
```

といったAIの状態を、画面を見るだけで把握できるようになる。

---

# 39. 採用する最終方針

```
キャラクター
→ 上半身

素材
→ PNG差分

表情制作
→ Qwen Image Edit 2511

位置固定・仕上げ
→ Photoshop

初期表情
→ Neutral / Smile / Surprised / Troubled / Sleepy

瞬き
→ 3段階

口パク
→ 3段階

デスクトップ表示
→ PySide6

シエルとの通信
→ localhost WebSocket

描画
→ イベント発生時のみ更新

待機時
→ 静止状態

将来
→ Live2D等へ差し替え可能
```

この構成が、**実装難度・軽さ・表現力・将来の拡張性のバランスが最も良い構成**となる。
