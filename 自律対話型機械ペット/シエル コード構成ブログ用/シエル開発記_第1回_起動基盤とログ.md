# Tapo C200をAIペット化する計画、まずは「起動してログが出る」ところから作る【シエル開発記 第1回】

Tapo C200をただの見守りカメラとして使うのは、ちょっともったいない。

パン・チルトで首を振れるし、RTSPで映像も取れるし、見た目もどことなくロボットっぽい。ここにAIを乗せたら、ただのカメラではなく、部屋にいる小さな機械ペットになるのでは？ というのが今回の出発点です。

ということで、Tapo C200をAIペット「シエル」として育てていく連載を始めます。

最終的には、カメラで部屋を見て、マスターの入退室に反応して、Ollamaで会話して、GPT-SoVITSで声を出して、Discordから操作できて、記憶や感情っぽい状態まで持つ常駐型AIペットを目指します。

……と書くといきなりエグい規模に見えますが、最初から全部やると確実に沼ります。

なので第1回では、**起動する・必要なフォルダを作る・ログを出す**ところだけを作ります。

これだけです。

でも、ここを雑にすると後で地獄を見ます。たぶん。

## この連載で作りたい完成形

今回作る「シエル」は、単なるチャットボットではありません。

```text
カメラで部屋を見る

人物検出でマスターの在席を判断する
```

文字にすると完全に趣味の魔改造です。

カメラとして見ればTapo C200は高級機ではありません。α7VやRSC2みたいなバチバチの機材感はありません。

ただ、首を振る小型カメラにAIを乗せると、急に「機材」ではなく「個体」っぽく見えてくる。

ここがこの計画の中核です。

## 秘密情報はコードに直書きしない

AIペット化計画では、あとからいろいろな秘密情報を扱います。

たとえば以下です。

- Discord Bot Token
- Discord Channel ID
- Discord User ID
- RTSP URL
- カメラのユーザー名
- カメラのパスワード
- Nature Remo Access Token
- ローカルIPアドレス
- 個人名が入ったファイルパス

これらをブログにそのまま載せるのは普通に危険です。

特にDiscord Bot TokenやカメラのURLは、外に出すとかなりまずいです。

なので、この連載では秘密情報を直接コードに書かず、基本的には `.env` や環境変数から読み取る形にします。

今回はまだ本物のトークンは使いませんが、最初から `.env.example` を用意しておきます。

### .env.example

```env
# Discord Bot Token。実際の値は .env にだけ書く
DISCORD_TOKEN=

# Discordの通常会話チャンネルID
DISCORD_CHANNEL_ID=

# DiscordのログチャンネルID
DISCORD_LOG_CHANNEL_ID=

# RTSP URL。例はダミー
RTSP_URL=rtsp://user:password@192.168.xxx.xxx:554/stream1

# OllamaのURL。別PCで動かす場合はIPを変更する
OLLAMA_URL=http://127.0.0.1:11434

# Nature Remo。使う場合だけ設定
NATURE_REMO_ACCESS_TOKEN=
```

`.env.example` は公開してOKです。

ただし、本物の `.env` は公開しません。

`.gitignore` を使う場合は、以下を入れておくと安全です。

```gitignore
.env
logs/
debug/
temp/
*.log
```

これで、うっかり秘密情報やログを公開するリスクを減らせます。

ここから実際にコードを書きます。

今回の目的は、以下です。

- スクリプトを起動できる
- 必要なフォルダを自動生成する
- JSONファイルを保存できる
- ログファイルに起動記録を残せる
- エラーが起きても原因を追える

この時点でAIらしさはありません。

でも、土台としてはかなり重要です。

後でOllama、GPT-SoVITS、RTSP、YOLO、Discordを追加した時、全部の状態をログで追えるようになります。

## 今回のコード

`Ciel` フォルダを作り、その中に `ai_pet_brain.py` を作成します。

```python
# -*- coding: utf-8 -*-
"""
AIペット「シエル」最小起動基盤
第1回：フォルダ構成・設定ファイル・ログ基盤
"""

from __future__ import annotations

import json
import logging
import os
import platform
import sys
import traceback
from datetime import datetime
from pathlib import Path
from typing import Any, Dict


# ==============================
# 基本フォルダ構成
# ==============================

BASE_DIR = Path(__file__).resolve().parent
DATA_DIR = BASE_DIR / "data"
ASSETS_DIR = BASE_DIR / "assets"
MODELS_DIR = BASE_DIR / "models"
MODULES_DIR = BASE_DIR / "modules"
DEBUG_DIR = BASE_DIR / "debug"
BACKUP_DIR = BASE_DIR / "backup"
TEMP_DIR = BASE_DIR / "temp"
LOGS_DIR = BASE_DIR / "logs"

STATE_FILE = DATA_DIR / "ai_pet_state.json"
LOG_FILE = LOGS_DIR / "ciel.log"

ALL_DIRS = [
    DATA_DIR,
    ASSETS_DIR,
    MODELS_DIR,
    MODULES_DIR,
    DEBUG_DIR,
    BACKUP_DIR,
    TEMP_DIR,
    LOGS_DIR,
]


# ==============================
# 初期化処理
# ==============================

def ensure_directories() -> None:
    """シエルに必要なフォルダを作成する。"""
    for directory in ALL_DIRS:
        directory.mkdir(parents=True, exist_ok=True)


def setup_logger() -> logging.Logger:
    """コンソールとファイルの両方へログを出す。"""
    logger = logging.getLogger("ciel")
    logger.setLevel(logging.INFO)
    logger.handlers.clear()

    formatter = logging.Formatter(
        fmt="%(asctime)s [%(levelname)s] %(message)s",
        datefmt="%Y-%m-%d %H:%M:%S",
    )

    console_handler = logging.StreamHandler(sys.stdout)
    console_handler.setFormatter(formatter)

    file_handler = logging.FileHandler(LOG_FILE, encoding="utf-8")
    file_handler.setFormatter(formatter)

    logger.addHandler(console_handler)
    logger.addHandler(file_handler)

    return logger


# ==============================
# JSON読み書き
# ==============================

def load_json(path: Path, default: Dict[str, Any]) -> Dict[str, Any]:
    """JSONファイルを読み込む。存在しない場合はdefaultを返す。"""
    if not path.exists():
        return default

    try:
        with path.open("r", encoding="utf-8") as f:
            data = json.load(f)
        if isinstance(data, dict):
            return data
        return default
    except Exception:
        return default


def save_json(path: Path, data: Dict[str, Any]) -> None:
    """JSONファイルへ保存する。"""
    path.parent.mkdir(parents=True, exist_ok=True)
    with path.open("w", encoding="utf-8") as f:
        json.dump(data, f, ensure_ascii=False, indent=2)


# ==============================
# 状態ファイル
# ==============================

def create_initial_state() -> Dict[str, Any]:
    """初期状態を作成する。"""
    now = datetime.now().isoformat(timespec="seconds")
    return {
        "name": "Ciel",
        "version": "0.1.0",
        "status": "initialized",
        "created_at": now,
        "last_started_at": now,
        "environment": {
            "python": sys.version.split()[0],
            "platform": platform.platform(),
        },
    }


def update_startup_state(logger: logging.Logger) -> None:
    """起動時の状態をJSONに保存する。"""
    state = load_json(STATE_FILE, create_initial_state())
    state["status"] = "running"
    state["last_started_at"] = datetime.now().isoformat(timespec="seconds")
    state["environment"] = {
        "python": sys.version.split()[0],
        "platform": platform.platform(),
    }
    save_json(STATE_FILE, state)
    logger.info("状態ファイルを更新しました: %s", STATE_FILE)


# ==============================
# 環境変数確認
# ==============================

def get_env_value(key: str, default: str = "") -> str:
    """環境変数を取得する。未設定ならdefaultを返す。"""
    return os.environ.get(key, default)


def log_environment_summary(logger: logging.Logger) -> None:
    """秘密情報を出さない範囲で環境設定を確認する。"""
    ollama_url = get_env_value("OLLAMA_URL", "http://127.0.0.1:11434")

    logger.info("Python: %s", sys.version.split()[0])
    logger.info("Platform: %s", platform.platform())
    logger.info("BASE_DIR: %s", BASE_DIR)
    logger.info("OLLAMA_URL: %s", ollama_url)

    # Tokenなどの秘密情報は値を出さず、設定済みかどうかだけ確認する
    secret_keys = [
        "DISCORD_TOKEN",
        "RTSP_URL",
        "NATURE_REMO_ACCESS_TOKEN",
    ]
    for key in secret_keys:
        logger.info("%s: %s", key, "設定あり" if os.environ.get(key) else "未設定")


# ==============================
# main
# ==============================

def main() -> None:
    ensure_directories()
    logger = setup_logger()

    logger.info("==============================")
    logger.info("AIペット『シエル』起動しました")
    logger.info("==============================")

    log_environment_summary(logger)
    update_startup_state(logger)

    logger.info("第1回の起動確認が完了しました")
    logger.info("今回はここで正常終了します")


if __name__ == "__main__":
    try:
        main()
    except Exception:
        ensure_directories()
        error_log = LOGS_DIR / "ciel_error.log"
        with error_log.open("a", encoding="utf-8") as f:
            f.write("\n" + "=" * 60 + "\n")
            f.write(datetime.now().isoformat(timespec="seconds") + "\n")
            f.write(traceback.format_exc())
        raise
```

## コードの意味

### BASE_DIRを基準にする

```python
BASE_DIR = Path(__file__).resolve().parent
```

ここがかなり大事です。

Pythonは起動方法によって、現在位置がズレることがあります。

たとえば、PowerShellから起動した場合、バッチファイルから起動した場合、ショートカットから起動した場合で、相対パスの基準が変わることがあります。

そこで、`ai_pet_brain.py` が置かれている場所を基準にします。

これで、どこから起動しても `data` や `logs` の保存先が安定します。

### フォルダを最初に作る

```python
for directory in ALL_DIRS:
    directory.mkdir(parents=True, exist_ok=True)
```

必要なフォルダがなければ自動作成します。

この段階で `data`、`debug`、`temp` などを作っておくことで、あとから機能を追加した時に保存先で迷いません。

### printではなくloggingを使う

```python
logger.info("AIペット『シエル』起動しました")
```

`print()` でも画面には出せます。

ただ、常駐型AIでは画面に出すだけだと足りません。

あとから「昨日の夜に何が起きた？」となった時、ファイルに残っていないと確認できないからです。

なので今回は、コンソールと `logs/ciel.log` の両方にログを出します。

### JSONで状態を保存する

```python
STATE_FILE = DATA_DIR / "ai_pet_state.json"
```

今後、シエルには記憶、感情、好奇心、カメラ状態などを持たせていきます。

いきなりデータベースを使ってもいいのですが、最初はJSONで十分です。

軽いし、テキストエディタで中身を確認できるし、壊れた時も原因を追いやすい。

こういう趣味開発では、確認しやすさを優先します。

## よくある失敗

### フォルダの場所が思っていた場所と違う

`BASE_DIR` を使わずに相対パスだけで書くと、起動場所によって保存先がズレることがあります。

今回のコードでは、`ai_pet_brain.py` の場所を基準にしているので、この問題を避けやすくしています。

### ログファイルが作られない

`logs` フォルダを作る前に `FileHandler` を作ると失敗します。

そのため、今回は必ず先に `ensure_directories()` を実行しています。

### 日本語が文字化けする

ログやJSONを保存する時は、`encoding="utf-8"` を指定します。

```python
with path.open("w", encoding="utf-8") as f:
```

これを入れておくと、日本語のログや状態ファイルが扱いやすくなります。

### 秘密情報をログに出してしまう

これはかなり危険です。

たとえばDiscord TokenやRTSP URLをログにそのまま出すと、ログファイルを共有した時に漏れます。

今回のコードでは、秘密情報は値そのものを出さず、`設定あり` / `未設定` だけを出すようにしています。

## 今回のまとめ

今回は、AIペット「シエル」の最初の土台を作りました。

やったことは地味です。

- フォルダ構成を決めた
- 秘密情報を直書きしない方針にした
- ログを出せるようにした
- JSONで状態を保存できるようにした
- `python ai_pet_brain.py` で起動確認できるようにした

まだAIは喋らないし、カメラも見ません。

でも、ここができていれば、次から機能を足していけます。

いきなり全部載せの魔改造をすると、エラーが出た瞬間に原因が分からなくなります。

まずは起動する。

ログが残る。

状態が保存される。

この地味な3点セットが、後工程の不具合調査で重要になります。

次回は、Ollamaを使って、キーボード入力に対してシエルが日本語で返答するところまで作ります。

では、また。
