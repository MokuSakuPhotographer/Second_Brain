# 主人公側・今州側の主要キャラ

## 漂泊者

|          |                              |
| -------- | ---------------------------- |
| 項目       | 内容                           |
| 立場       | 主人公。記憶を失って目覚めた謎の存在           |
| どういうキャラか | 自分が何者かを知らないが、異常な共鳴能力を持つ存在    |
| 第一章での役割  | 今州で今汐の印を追い、残星組織や悲鳴級災厄と関わっていく |
| 関係性      | ほぼ全キャラが「漂泊者は何者なのか」を中心に動く     |

第一章では、主人公は「今州に来た外部者」から「今州を救った存在」へ変化します。第1幕では白芷の検査や疑似音場の異常によって普通の共鳴者ではないことが示され、第6幕では無妄者との戦いで消滅属性が解放されます。 

  

## 秧秧

|   |   |
|---|---|
|項目|内容|
|立場|今州側の共鳴者。夜帰の偵察・案内役に近い存在|
|どういうキャラか|落ち着いた性格で、主人公に寄り添う初期相棒|
|主人公との関係|最初から主人公を支え、今州の状況や主人公自身の異変を説明する|
|重要度|高い。第一章全体で主人公に最も近い同行者の一人|

秧秧は、主人公にとって「今州の入口」です。第1幕では主人公の謁見手続きを進め、第7幕では主人公の中で眠っていたアブについて説明します。戦闘面よりも、主人公の不安を整理し、今州側と主人公をつなぐ役割が強いです。

熾霞は、秧秧よりも親しみやすい「街の案内人」です。第1幕では主人公を中央信号塔へ案内し、今州の基本的な仕組みを見せます。物語上は、主人公が今州を“知らない場所”ではなく“守るべき街”として見るきっかけを作るキャラです。

# 結論

第一章で最も重要なのは、以下の理解です。

今州側は主人公を“外から来た謎の存在”として警戒しつつも受け入れていく。  
残星組織は主人公を“利用価値のある特別な存在”として見ている。  
黒海岸は主人公を“過去に関係する存在”として扱う。

つまり第一章の登場キャラは、全員がそれぞれ違う方向から、主人公に対してこう問いかけています。

「お前は何者なのか」

この問いが、第一章全体のキャラ関係の核です。

---

1章全体の大筋

記憶を失った漂泊者が今州に入り、令尹・今汐から与えられた「印」の謎を追う。  
その過程で、残星組織、無音区、悲鳴、歳主・角、黒海岸、テティスシステムといった大きな設定に触れていく。  
要するに1章は、**「漂泊者は何者なのか」と、「今州を脅かす災厄をどう防ぐのか」**を追う章です。

  

## 第1幕「惹かれ合う声」

役割：今州到着、今汐の“試験”開始

漂泊者は秧秧、熾霞、白芷たちと共に今州城へ到着します。白芷は研究院へ、秧秧は報告と謁見手続きへ向かい、漂泊者は熾霞に案内されて今州の仕組みを知っていきます。中央信号塔ではマップ情報を登録し、今州という都市が情報・防衛・通信の中枢を持つ管理都市であることが示されます。 

漂泊者は令尹・今汐に会うため辺庭へ向かいますが、今汐本人はいません。代わりに近衛の散華が現れ、今汐からの贈り物として4つの印を渡します。内容は、黒い果実、葉っぱ、小型装置、飴。この印の謎を解けば、漂泊者が求める答えに近づけると示されます。 

その後、漂泊者は研究院で白芷やモルトフィーと共に印を分析します。小型装置は日時計のような仕掛けで、飴はただの飴ではなく、成分分析で経口型ワクチンだと判明します。しかも期限切れから20年経っており、20年前の疫病と関係している可能性が浮上します。 

さらに、漂泊者は疑似音場で戦闘テストを受けますが、そこで正体不明の残像に襲われます。これは漂泊者自身の内面や周波数が、疑似音場に異常な影響を与えたことを示しており、漂泊者が普通の共鳴者ではないことを強く匂わせます。 

この幕の意味

第1幕は、今州編の導入です。  
今汐は最初から漂泊者に直接会わず、印という形で「試験」または「誘導」を行っています。ここで重要なのは、今汐が漂泊者を警戒しているだけでなく、漂泊者なら謎を解けるはずだと見込んでいる点です。

  

## 第2幕「止め鐘を撞く行陣」

役割：今州の軍事状況と忌炎の紹介

研究院を出た漂泊者は熾霞と会話し、今州城の外へ向かいます。目的地は夜帰の駐屯地。ここで都市の外側が安全ではなく、残像や無音区の脅威が常に存在していることが見えてきます。 

道中では偵察装置を修理し、戦場の情報網を復旧させます。これは単なるギミックではなく、今州が残像との戦争を続けるために、前線の観測・通信・防衛設備に依存していることを示しています。 

終盤では黒石駐屯地へ向かい、将軍・忌炎が登場します。忌炎は前線で残像と戦い続ける今州軍の象徴です。ここで物語は、漂泊者個人の謎解きから、今州全体を巻き込む戦争へと視野を広げます。 

この幕の意味

第2幕は、**「今州はすでに戦時下にある」**ことを示す幕です。  
漂泊者はまだ外来者ですが、今州の危機を目撃することで、以後の防衛戦に関わる下地が作られます。

  

## 第3幕「策を奔らせて残星を候ふ」

役割：残星組織とスカーの思想提示

漂泊者は印の手がかりを追って祈池村へ向かいます。祈池村はすでに荒廃しており、複数の残像が出現します。漂泊者は無音区を処理し、スキャンで村の異常を調査していきます。 

そこで現れるのがスカーです。スカーは単なる敵キャラではなく、残星組織の思想を語る存在として登場します。彼は漂泊者を幻境へ引き込み、村の過去や人間の弱さ、犠牲、選別のようなテーマを突きつけます。

スカーの幻境では、漂泊者は足場を進み、残像を倒しながら奥へ進みます。最終的にスカーと戦闘になりますが、この戦闘は「勝って終わり」というより、残星組織が漂泊者に強い関心を持っていることを示すイベントです。 

その後、漂泊者は壊れた木札や古い日記を回収します。これにより祈池村で過去に何が起きたのか、そして今汐の印がなぜここへ導いたのかが少しずつ見えてきます。 

この幕の意味

第3幕は、残星組織の顔見せです。  
スカーは漂泊者に対して、今州側とは違う解釈で世界を見せようとします。以後の物語で重要になる、**「この世界の災厄をどう受け止めるか」**という思想対立が始まります。

  

## 第4幕「激突する辺庭」

役割：印の謎解き完了、スカー捕縛

第1幕から続いていた日時計の謎がここで動きます。漂泊者は研究院で得た情報をもとに、日時計を「未の刻」「南の朱雀」に合わせます。これにより、今汐が仕掛けた導線が次の段階へ進みます。 

漂泊者は辺庭の隠された空間、瑝覧類書へ入ります。内部では宮音台に5つの「音」を集める必要があり、これは今州の記録・周波数・歴史をたどるような構造になっています。 

ここで漂泊者は、今汐の意図にさらに近づきます。今汐は漂泊者をただ招いただけではなく、印を通じて特定の場所へ導き、同時に残星組織の動きも誘導していたと考えられます。

終盤ではスカーが再び現れます。漂泊者はスカーと戦闘し、辺庭側の仕掛けによってスカーは捕縛されます。Game8の整理でも、この幕は「今汐の手がかりを解き、隠された大図書館で会うはずだったが、旧敵が現れ、罠に落ちる」という構図で説明されています。 

この幕の意味

第4幕で、第1幕からの「印の謎解き」は一区切りします。  
今汐の狙いは、漂泊者の能力と判断力を測ること、そして残星組織をあぶり出すことだったと判断できます。

  

## 第5幕「雨が空に堕ちる頃に」

役割：黒海岸への接触、悲鳴の脅威が明確化

第5幕では、漂泊者は今州城の裏山でヴェリーナと会い、その後ツバキと接触します。ツバキは黒海岸と関係する人物で、漂泊者に強い興味を示します。ここから物語は、今州内部だけでなく、世界規模で異常を観測している黒海岸へ広がります。

その後、漂泊者は秧秧、熾霞と合流し、アールトとアンコに出会います。アールトとアンコは黒海岸側の人物で、漂泊者は彼らを追う形で稷廷の研究室へ向かいます。GameWithの攻略チャートでも、ツバキとのイベント後に秧秧・熾霞と合流し、アールト＆アンコと会話した後、アールトを追う流れになっています。 

稷廷の研究室では、回転盤やバッテリーのギミックを解きながら奥へ進み、機械アボミネーションと戦闘します。ここで旧文明・研究施設・黒石技術・異常現象の関係が示されます。 

この幕の核心は、「雨が空へ堕ちる」ような異常現象と、悲鳴級の災厄の兆候です。Game8では、第5幕を「黒海岸を探す中で、逆流する雨と、文明を呑み込む可能性がある悲鳴級存在の覚醒が示される幕」と説明しています。 

この幕の意味

第5幕は、第6幕の大決戦への準備です。  
ここで敵の規模が一段階上がります。単なる残像退治ではなく、国を滅ぼしうる災厄が目覚めようとしていることが判明します。

  

## 第6幕「千里の猛襲」

役割：今州防衛戦、無妄者との決戦

第6幕は、1章前半のクライマックスです。今州全域で残像が暴れ、戦況は全面戦争に近い状態になります。漂泊者は忌炎たちと共に前線へ出て、基地周辺の敵を倒していきます。 

途中で中ボス「雲閃のウロコ」と戦い、さらに駐屯地で作戦を決めます。ここで漂泊者は完全に今州側の戦力として組み込まれ、ただの客人ではなく、防衛戦の中心人物として扱われるようになります。 

その後、砲台周辺の敵を倒し、空中廃墟を登りながら戦場の中心へ向かいます。さらに「無情のサギ」と戦い、最後に「無冠者」「無妄者」との戦闘になります。第6幕の攻略チャートでも、最終的に無冠者・無妄者と戦い、主人公の「消滅」属性が解放される流れになっています。 

物語上は、悲鳴級存在の覚醒を止める戦いです。漂泊者は自分の中に眠る力を発現させ、今州を滅亡から救います。この戦いによって、漂泊者は今州にとって単なる謎の人物ではなく、実際に国を救った存在になります。

この幕の意味

第6幕は、今州防衛戦の決着です。  
ここまでの1章前半は、**「今州を救う英雄として漂泊者が受け入れられる物語」**と見てよいです。

  

## 第7幕「今州の来訪者」

役割：今汐と角の真相、乗霄山編

第7幕は、第6幕後の後日談ではなく、1章の核心に踏み込む続編です。今州城で秧秧と熾霞に会い、漂泊者の中で眠っていた小さな存在・アブについて説明を受けます。 

漂泊者は記憶を取り戻すため、今汐を待ちますが、今汐は戻ってきません。そんな中、夢で歳主・角から「乗霄山」の名を聞きます。近くの老人の助言を受け、漂泊者は乗霄山へ向かう流れになります。 

怨鳥の沼で案内人・長離と出会い、乗霄山へ移動します。乗霄山は時間の流れが異常な地域で、虹鎮では時間が止まったような光景が広がっています。漂泊者は今汐の痕跡を追い、虹鎮の代表者・辛夷から異変と今汐について話を聞きます。 

その後、漂泊者は叩天関へ向かい、今汐と合流します。今汐は歳主・角のもとへ向かおうとしており、漂泊者も協力します。途中で心核を入手し、龍眠庭へ入るためのロックを解除します。長離は残星組織の襲撃を引き受け、漂泊者と今汐を先へ進ませます。 

龍眠庭では、角と会話し、最終的に今汐が角と戦います。戦闘は今汐操作で行われ、物語上は今汐が歳主・角と向き合い、自らの役目を果たす場面です。 

この幕で重要なのは、今汐が単なる今州の統治者ではなく、角と深く結びついた存在だということです。角は今州を守る歳主であり、今汐はその力と運命を背負う立場にあります。

この幕の意味

第7幕は、今汐の物語です。  
第6幕までは漂泊者が今州を救う話でしたが、第7幕では今汐が自分の運命を選び、角と向き合います。漂泊者はその証人であり、助力者です。

  

## 第8幕「岸の最果てまで」

役割：黒海岸、ショアキーパー、漂泊者の過去

第8幕は、舞台が黒海岸へ移ります。漂泊者は帰来の港で秧秧と合流し、釉瑚とも出会います。来歴不明の古物を追う流れから、黒海岸の研究員、異常残像、謎の番号「HL-1」などに関わっていきます。 

その後、漂泊者は黒海岸本部へ移動し、アールトとも合流します。黒海岸では、データ回収ロボット、信号塔、人事担当のモニカ、花園など、今州とはまったく違う組織構造が描かれます。黒海岸は単なる秘密組織ではなく、世界規模の異常を観測・記録・処理する研究機関として描かれます。 

中盤では、黒海岸各地に発生した汚染コアを除去していきます。クココから汚染除去権限を得て、汚染コアを破壊しながら進む構造です。これは、黒海岸そのものが何らかのデータ汚染・異常侵食に襲われていることを示しています。 

さらに生命の方舟、エラー収容所、調律ホールへ進み、ネクロ・スターやデータ汚染の問題に触れます。エラー収容所ではネクロ・スターを調べ、燎原の炎騎・焼身止炎と戦闘し、ネクロ・スターのデータ断片を確認します。 

この幕の中心人物がショアキーパーです。彼女は黒海岸とテティスシステムに深く関わる存在で、漂泊者の過去にも関係しています。Game8では、第8幕を「ラメントの脅威を受け、漂泊者が黒海岸本部へ向かい、失われた過去の真実と未来への道を知る幕」と整理しています。 

終盤では、漂泊者はテティスシステムのもとへ向かいます。ショアキーパーの援護を受けながら進み、最奥で「フェイタルエラー・テティスシステム」と戦闘します。この戦闘では使用キャラが漂泊者・消滅に固定されます。 

最終的に黒海岸は安定し、ショアキーパーは救われます。Game8の整理では、ショアキーパー救出に成功し、テティスシステムが安定し、漂泊者の過去が明かされ、漂泊者が自分の運命の入口に立つ、という形で第8幕が締められます。 

この幕の意味

第8幕は、1章の終点であり、次章以降への橋渡しです。  
第1〜7幕が「今州と角の物語」だったのに対し、第8幕は漂泊者自身の過去、黒海岸、世界規模のラメント対策へ話を広げます。

  

## 1章を一文でまとめるなら

記憶を失った漂泊者が今州で今汐に導かれ、残星組織と悲鳴級災厄を退け、さらに角と黒海岸を通じて、自分が世界の運命に関わる存在だと知っていく物語です。
