# SL-A251

#ホームシアター #サブウーファー #Onkyo

## 基本情報

- **メーカー**: Onkyo
- **製品名**: SL-A251
- **カテゴリ**: アンプ内蔵サブウーファー
- **所有状況**: 所有

## 仕様

| 項目 | 内容 |
|---|---|
| 形式 | アンプ内蔵バスレフ型 |
| 用途 | LFE / 低域補強 |
| ユニット | 20cm A-OMFモノコックコーン |
| 実用最大出力 | 75W、5Ω、JEITA |
| 周波数特性 | 30Hz-200Hz、FILTER時 |
| DIRECT時 | 30Hz-1.5kHz |
| 入力インピーダンス | 4.7kΩ、スピーカー入力 |
| ライン入力インピーダンス | 54kΩ |
| ハイカットフィルター | 可変、50-200Hz |
| サイズ | 255 x 399 x 443mm |
| 重量 | 13.5kg |
| 付属品 | 接続用ピンコード、コルクスペーサー、グリルネット等 |

## 導入目的

- ホームシアターの低域とLFEを担当するサブウーファー。
- [[TX-NR646]] のサブウーファー出力に接続し、[[D-509E]] や [[D-509C]] だけでは不足する低域を補う。
- 映画の爆発音、環境音、音楽の低域の量感を補強する。

## 接続メモ

| 接続先 | 役割 |
|---|---|
| [[TX-NR646]] | サブウーファー出力 |
| [[D-509E]] | フロント低域とのつながり |
| [[D-509C]] | セリフ帯域とのバランス |
| [[D-109M]] | サラウンド側との低域管理 |

## 注意点

- 設置位置で低域の量感が大きく変わるため、壁際・角置き・リスニング位置で調整する。
- AVアンプ側のクロスオーバー設定と、サブウーファー側のフィルター設定を二重にしない。
- 夜間視聴では低域が床・壁を伝わりやすいため、音量と防振に注意する。

## 調査メモ

- 価格.comとニュースリリース系情報で、30Hz-200Hz、75W、20cmユニット、255 x 399 x 443mm、13.5kgを確認。
- 取扱説明書系資料でFILTER / DIRECT動作と接続情報を確認。
