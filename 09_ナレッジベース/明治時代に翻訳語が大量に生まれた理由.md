# 明治時代に翻訳語が大量に生まれた理由

> [!summary] 要点
> 幕末から明治にかけて日本は、西洋の政治・法律・科学・思想を短期間で学び、制度や教育に取り入れる必要があった。その際、既存の日本語では説明しにくい概念が大量に現れたため、**漢語の意味を拡張したり、新しい漢字熟語を作ったりする翻訳活動が急増した**。翻訳元は英語だけでなく、オランダ語・フランス語・ドイツ語、さらには中国語に翻訳された西洋書籍も含まれる。[1][2]

## 1. なぜ明治前後に集中したのか

### 国家の近代化に必要だった

幕末の開国と明治維新を経て、日本は外国との外交、法制度の整備、産業・軍事技術の導入などを急いだ。機械そのものを輸入しても、その構造や背景にある学問を説明する言葉がなければ、知識を広く共有できない。[1]

必要となった言葉は技術用語だけではない。国家・社会・権利・自由といった、人間と制度の関係を説明する語彙も重要になった。

### 教科書と教育の需要が増えた

1872年（明治5年）には「学制」が公布され、近代的な学校制度の整備が進んだ。国立国会図書館によると、教科書需要の急増を背景に、**1873年末頃までに物理学関係の書籍だけでも50点以上刊行された**とみられる。[3]

教育が広がるほど、専門家だけでなく教師や生徒が共通して理解できる訳語が必要になった。

## 2. 新しい言葉はどう作られたのか

訳語の成立には複数の方法があった。[2]

| 方法 | 例 | 仕組み |
|---|---|---|
| 江戸時代の蘭学訳語を引き継ぐ | 神経 | 西洋医学を訳す過程で作られた語を継承 |
| 中国語訳された西洋書から借りる | 権利 | 漢訳洋書の用語を参照し、法学の訳語として利用 |
| 古い漢語に新しい意味を与える | 自由・経済・文化 | 既存の語を西洋の概念に対応させる |
| 漢字を組み合わせて新語を作る | 哲学・科学 | 漢字の意味を利用して学術概念を表現する |

**「明治の翻訳語＝明治時代にゼロから発明された語」ではない。** すでに存在した漢語の意味を変えたり、江戸時代の訳語を使い続けたり、中国で作られた訳語を取り入れたりした例も多い。[2]

### 「哲学」の例

西周（にし・あまね）は *philosophy* などの西洋学術語を日本語で表す仕事を進め、「哲学」をはじめ多くの訳語の形成に関わった。[2] 漢字による短い熟語は、教科書の見出しや「○○学」のような学問名にも使いやすかった。

### 「自由」の例

「自由」は明治以前からあった漢語である。*Liberty*・*freedom* の訳語として使われることで、「好きなようにする」だけでなく、**政治的・法的な権利としての自由**が表されるようになった。[4]

詳しくは [[「自由」と「不自由」の語源と意味の変遷]] を参照。

## 3. 明治以前にも翻訳語は作られていた

1774年（安永3年）に刊行された『解体新書』は、西洋医学書の日本語訳である。江戸時代の蘭学者は、すでに西洋の知識を説明するために「神経」のような言葉を工夫していた。[2][5]

したがって、明治時代は翻訳が突然始まった時代ではなく、**江戸時代からの翻訳技術が、より多くの分野・言語・読者へと広がった時代**である。

| 時期 | 翻訳の広がり |
|---|---|
| 江戸中期〜後期 | オランダ語を通じた医学・自然科学などの翻訳が進む |
| 幕末 | 外交・政治・制度などへの関心が拡大。福沢諭吉『西洋事情』初編は1866年刊行 |
| 明治初期 | 学校制度・行政・法律・産業の近代化とともに訳語の需要が急増 |
| 明治中期以降 | 辞書・教科書・新聞などを通じて多くの訳語が定着 |

## 4. 翻訳語は日本語だけにとどまらなかった

日本で形成・定着した近代漢語の一部は、近代化を進める中国にも伝わった。日本語で西洋の思想を学んだ中国人留学生や翻訳者が、漢字で書かれた新しい概念を中国語に取り入れたためである。[2]

ただし、**漢字で書かれた近代語がすべて日本製というわけではない。** 中国古典の既存語、日本の造語、漢訳洋書からの借用など、成立経路は語ごとに調べる必要がある。

## 5. 翻訳が変えたもの

翻訳は単なる外国語の置き換えではなかった。新しい語彙が共有されることで、法律を議論し、科学を教え、政治制度を比較するための共通の道具が整った。

例えば「個人」という語が定着すると、「社会」「国家」と対比しながら「個人の自由」「個人主義」を論じやすくなる。[6]

つまり、**言葉が増えたことは、新しい知識を理解し、議論するための枠組みが増えたことでもある**。
