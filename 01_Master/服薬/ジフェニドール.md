# ジフェニドール

## 薬の基本情報

| 項目 | 内容 |
|---|---|
| 一般名 | ジフェニドール塩酸塩 |
| 分類 | 鎮暈薬（めまいの治療薬） |
| 主な効能・効果 | 内耳障害に基づくめまい |
| 現在の服薬 | **朝1錠・晩1錠**（本人申告） |
| 1錠の規格 | **未確認（mgを薬袋で確認）** |
| 製品名・メーカー | 未確認 |

## 作用

内耳や前庭系に関わるめまいを抑える目的で使われる。めまいの原因疾患自体を必ず治す薬ではなく、症状の改善を目的とする。

## 主な副作用

- 消化器：**胃・腹部不快感、胸やけ、悪心・嘔吐、胃痛**、口渇、食欲不振。
- 神経・全身：浮動感、頭重感、頭痛、眠気、動悸。
- その他：発疹、ピント調節の障害、排尿困難など。まれに錯乱・幻覚など。

## 注意事項

緑内障、排尿障害、胃腸管閉塞、腎機能障害がある場合は処方医への申告が必要。抗コリン作用に関連する副作用がある。今回のような上腹部のムカムカ・胸焼けも添付文書にあるが、**服薬後に起きたことだけで副作用と確定できない**。
