# Current Knowledge Map

このChatGPT_KBは、Deep ResearchにVault全体を読ませず、必要な知識だけを高速に参照させるための要約レイヤー。

## 含まれる領域

- Camera: 撮影機材、レンズ用途、ライティング、編集ワークフロー
- Media: 観たアニメ、好きなキャラ、ブラック・ミラーの評価とテーマ

## 運用方針

- 詳細ノートは通常Vaultに残す。
- ChatGPT_KBには要約・索引・傾向だけを置く。
- Deep Researchでは基本的にこのChatGPT_KBだけを読ませる。
- 新しい機材・作品を追加したら、必要に応じてKBの要約ノートだけ更新する。
